## 摘要
随着大型语言模型（LLM）作为通信代理被部署，代理间的通信是否会导致输出趋同？我们引入了BOUNDARY_SYNC协议，通过耦合放大因子（CAF = JSD_cond / JSD_baseline）测量表征耦合，其中CAF < 1表示同质化，CAF > 1表示多样化。在受控的GPT-4o实验中（N=30，约9,900次API调用），我们测量了文本和图像通信中的耦合。主要发现：（1）文本通信导致显著的同质化（CAF=0.803 [0.740, 0.873], d=1.30, p<0.001），通过无通信消融和提示扰动对照得到确认；（2）在模态内基线条件下，图像通信也导致同质化（CAF=0.834 [0.811, 0.858]），效果比例相当；（3）群体规模调节耦合方向——K=5产生同质化，而K=3产生CAF > 1.0（点估计值1.14和1.06，置信区间待定），表明向多样化的方向性转变；（4）跨模型复制显示出极端变异（CAF 0.034-0.803），其中DeepSeek受格式伪影主导；（5）耦合是无状态的——由提示上下文驱动而非累积更新，连续共识产生单调收敛。这些结果确立了LLM代理耦合在提示层面是真实、可测量且可控的，对多智能体系统设计具有直接影响。

## Abstract
As large language models (LLMs) are deployed as communicating agents, does inter-agent communication cause outputs to converge? We introduce BOUNDARY_SYNC, a protocol measuring representational coupling via the Coupling Amplification Factor (CAF = JSD_cond / JSD_baseline), where CAF < 1 indicates homogenization and CAF > 1 indicates diversification. In controlled GPT-4o experiments (N=30, ~9,900 API calls), we measure coupling in text and image communication. Key findings: (1) text communication causes significant homogenization (CAF=0.803 [0.740, 0.873], d=1.30, p<0.001), confirmed by no-communication ablation and prompt-perturbation controls; (2) image communication also homogenizes under within-modality baselines (CAF=0.834 [0.811, 0.858]), with comparable proportional effect; (3) group size moderates coupling direction -- K=5 produces homogenization while K=3 yields CAF > 1.0 (point estimates 1.14 and 1.06, CI pending), suggesting a directional shift toward diversification; (4) cross-model replication shows extreme variation (CAF 0.034-0.803), with DeepSeek dominated by format artifacts; (5) coupling is stateless -- driven by prompt context rather than cumulative updating, with continuous consensus producing monotonic convergence. These results establish LLM agent coupling as real, measurable, and controllable at the prompt level, with direct implications for multi-agent system design.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：当多个大语言模型（LLM）作为通信代理组成多智能体系统时，代理间的通信是否会导致其输出趋于同质化（即“表征耦合”），从而削弱多智能体架构的多样性优势？或者，通信是否会导致发散，进而放大噪声？
- **研究背景**：已有研究发现 LLM 组合中存在一致性现象（如代表性崩塌、标注任务中的收敛、从众效应、角色不稳定性等），但缺乏一套标准化的测量协议来：（a）将通信识别为因果机制；（b）在统一尺度上量化耦合强度；（c）区分瞬时的提示驱动效应与累积的意见更新。
- **整体意义**：理解并量化这种耦合，对于设计可靠的多智能体 LLM 系统至关重要——既能监测不必要的同质化，也能引导系统走向有益的多样性或共识。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将通信视为受控实验变量，通过比较通信条件下代理输出的 Jensen-Shannon 散度（JSD）与无通信基线的 JSD，定义耦合放大因子（CAF = JSD_cond / JSD_baseline）。CAF < 1 表示同质化（耦合导致输出趋同），≈1 表示独立，>1 表示多样化。
- **BOUNDARY_SYNC 协议**：
  - **步骤**：K 个代理对同一刺激进行 T=10 轮迭代分析，输出结构化概率分布（5 类）。
  - **通信注入**：每 3 步（冷却窗口）通过自然语言协议消息向代理注入“自身上一轮混合分布 + 其他代理的平均分布 + 权重指令”（如“自身 60%、邻居 40%”），消息持续 3 步，然后移除。
  - **混合权重**：默认 Beta(α=3, β=2)，期望自权重 0.6、邻居权重 0.4。混合通过提示拼接实现。
  - **基线条件**：C1（孤立基线，K=3，无通信），提供分母 JSD_baseline。
- **CAF 统计框架**：
  - 使用 bootstrap 95% 置信区间（2000 次重采样）及 jackknife 偏差校正（≤0.003 对 N=30）。
  - 效应量采用 Hedges' g，显著性检验采用 Welch t 检验。

## 6. 主要结论与发现

1. **文本通信导致显著同质化**：CAF=0.803 [0.740, 0.873]，d=1.30，p<0.001；无通信消融证实因果性（CAF=0.978, n.s.）；提示扰动对照确认效果是“社会性”的（无关文本 CAF=1.082，反而略微发散）。
2. **图像通信也导致同质化**：模态内 CAF=0.834 [0.811, 0.858]，比例效果与文本相当；但由于图像基线多样性更高，绝对多样性损失更大。
3. **群体大小调节耦合方向**：K=5 产生同质化（CAF<1），K=3 产生 CAF>1（点估计 1.14 和 1.06，置信区间待补充），表明存在一个临界规模 K* 使耦合方向反转。
4. **跨模型变异极大**：GPT-4o CAF≈0.80，Qwen CAF≈0.39，DeepSeek CAF≈0.034（受格式伪影主导，非真实社会耦合）。该 24× 范围应视为上界。
5. **耦合是无状态的**：邻域共识切换时 JSD 呈锯齿模式（共识轮降低，移除后立即反弹），无累积漂移；连续共识产生单调收敛（JSD 从 0.44 降至 0.001）。耦合由当前提示上下文驱动，而非累积更新。
6. **对实践的启示**：同质化风险在视觉任务中更大；可通过提示设计（保留/移除邻居信息）控制；群体大小是重要设计参数；模型选择需考虑耦合敏感性。

## 7. 优点

- **方法论创新**：首次提出标准化测量协议（BOUNDARY_SYNC）和统一指标（CAF），能跨条件、跨模型量化耦合强度，且可诊断伪影（如 DeepSeek 的格式崩塌）。
- **实验设计严谨**：包括多类控制（无通信消融、提示扰动、混合权重、群体规模、跨模型、连续/间歇共识），因果推断清晰。
- **统计稳健性**：使用 bootstrap CI、效应量、jackknife 偏差校正，报告结果开放可复现。
- **跨模态比较创新**：发现模态内 CAF 可比但绝对损失不同，贡献了“基线多样性决定绝对损失”的洞察。
- **揭示无状态机制**：与经典意见动力学（累积收敛）形成鲜明对比，推动对 LLM 社会行为理论的理解。

## 8. 不足与局限

- **自我锚定混淆**：协议消息包含代理自身历史输出，可能通过自我一致性（而非社会影响）降低 JSD。缺少“仅自身+权重”对照，报告 CAF 应视为社会耦合的上界。
- **群体大小与提示长度混淆**：K 越大，邻居摘要 token 越多，可能放大锚定效应。需固定长度摘要控制。
- **模态与刺激存在混淆**：文本条件无刺激，图像条件有刺激。虽通过模态内 CAF 归一化，但未完全解耦。N=5 的刺激先行实验显示保守方向，需 N=30 复制。
- **个体温度与角色异质性**：不同角色使用不同温度，可能影响基线多样性。需统一温度消融。
- **无状态测量协议不一致**：单轮动态实验使用 10 类协议而非主实验 5 类，数值不可直接比较。需用相同协议复制。
- **单任务领域**：仅评估性别刻板印象占用场景，结果对推理、代码生成等任务的外部泛化性未知。
- **跨模型伪影**：DeepSeek 结果被格式约束（JSON 输出、禁用推理）主导，不应视为其真实社会耦合强度。需统一自由格式协议复制。
- **CAF 比值偏差**：N=30 时 jackknife 校正很小，但小 N（如 Qwen N=10）偏差可能较大。
- **CAF 依赖分类数**：指标依赖输出类别数量和定义，需进一步检验对其他发散度量（如 TVD）的稳健性（文中 TVD 与 JSD 相关 r>0.95）。
