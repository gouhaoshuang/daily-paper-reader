## 摘要
人工智能工程正从大型语言模型的被动文本生成转向智能体驱动的任务执行，这在资源约束和环境不确定性下为长周期任务带来了新的可靠性挑战。传统的错误消除优化策略无法应对累积错误传播。本文提出分布式智能体系统，一种面向异构智能体间容错协作的设备-边缘-云框架。我们将智能体可靠性重新定义为系统级容错而非单轮零错误准确率，并提出双层容错架构：通过容错对齐实现单智能体执行可靠性，以及通过半形式化语言协议实现跨智能体通信可靠性。该框架为工业场景中可靠的异构具身智能体协作提供了实用的工程路径。

## Abstract
AI engineering is shifting from passive text generation by large language models (LLMs) to agent-driven task execution, creating new reliability challenges for long-horizon tasks under resource constraints and environmental uncertainty. Conventional error-elimination optimization strategies fail to address cumulative error propagation. This paper proposes Distributed Agent System (DAS), a device-edge-cloud framework for fault-tolerant collaboration among heterogeneous agents. We redefine agent reliability as system-level fault tolerance rather than single-turn zero-error accuracy, and present a two-layer fault-tolerance architecture: single-agent execution reliability via fault-tolerant alignment, and cross-agent communication reliability via semi-formal language protocols. This framework provides a practical engineering pathway for reliable heterogeneous embodied agents collaboration in industrial scenarios.

## 2. 方法论：核心思想、关键技术细节

### 2.1 分布式智能体系统框架
- **架构**：设备-边缘-云三层分布式协作。端设备（工业机器人、物联网终端等）处理实时感知与基本自主行动；边缘聚合区域数据并协调本地任务；云支持全局规划与优化。各层级独立自主决策，非集中调度。
- **与云端LLM多智能体系统的区别**：（1）异构设备-边缘-云智能体 vs. 同构云端基础模型；（2）严格端设备资源约束 vs. 充裕云计算资源；（3）优化目标：系统级长周期决策序列可靠性 vs. 单轮输出准确率；（4）核心挑战：错误累积与决策-物理执行耦合风险 vs. 问答与软件分解低风险任务；（5）应用场景：工业物理长周期操作 vs. 纯虚拟软件环境。

### 2.2 可靠性重定义
- **新定义**：智能体可靠性是在给定任务和环境约束下，稳定、一致、可控地完成闭环任务过程的系统级综合能力，包含安全行为、可信结果、可预测决策和容错异常处理。本质是任务执行收益与硬件、时间、人工干预成本之间的效用权衡。
- **核心转变**：从“错误消除”转向“不确定性管理与错误传播抑制”。

### 2.3 双层容错架构

#### 第一层：单智能体执行容错（容错可靠性对齐）
- **传统问题**：传统LLM智能体将未知场景下的不回答与错误输出等同视为负样本，输出动作空间主要是具体执行动作，缺乏拒绝、澄清、确认、任务委派等容错动作。
- **创新**：扩展动作空间为“犹豫动作空间”，包括主动拒绝、意图澄清、引导性问题、跨层任务路由等。采用基于强化学习的端到端可训练优化框架，实现数据驱动的动态适应。
- **实现路径**：
  - 显式建模知识边界外的犹豫动作：通过专用对齐训练，让轻量级智能体在任务参数缺失、场景未见或超出知识范围时选择容错动作而非强制执行。
  - DiSRouter机制：智能体评估自身能力，自主决定本地执行或向上委派任务，避免能力不匹配导致的执行失败。

#### 第二层：跨智能体通信容错（半形式化语言协议）
- **问题根源**：纯自然语言提示中隐含的任务约束、交接规则等模糊且不可验证，单节点语义偏差沿协作链传播放大。
- **核心设计**：将自然语言提示中的隐含规则（任务约束、转换策略、交接责任）转化为标准化、可检查、可执行、可审计的形式化协议结构。分离显式约束审计与隐式通用推理，平衡自然语言的表达灵活性与机器可验证性。
- **双重容错机制**：
  - 编译时：语法验证、逻辑检查、参数校验，在运行前阻断结构性错误。
  - 运行时：守卫机制实时约束智能体交互行为，阻断歧义信息、无效或违规操作，防止错误传播。
