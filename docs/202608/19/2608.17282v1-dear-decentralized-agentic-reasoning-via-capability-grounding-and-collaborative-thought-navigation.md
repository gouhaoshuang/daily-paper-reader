## 摘要
现有的智能体推理系统通常依赖中心化协议。这种设计引入了路由瓶颈和静态角色分配，在处理复杂的多模态查询时往往失效。我们提出DeAR（去中心化智能体推理），一个从中心控制转向自主点对点协作的框架。DeAR基于三种机制构建：（1）用于查询相关智能体特化的去中心化能力锚定，（2）用于目标智能体交互的思维图导航，以及（3）用于自适应错误修正的拓扑更新。在9个多样化的多模态推理和基于文本的问答基准测试上的评估表明，DeAR持续优于最近的基线方法，验证了智能体之间的去中心化和自适应协作能够提升知识密集型推理任务的准确性。源代码将在https://open_upon_acceptance上提供。

## Abstract
Existing agentic reasoning systems typically rely on centralized protocols. This design introduces routing bottlenecks and static role allocations that often fail when handling complex multimodal queries. We propose DeAR (Decentralized Agentic Reasoning), a framework that shifts from central control to autonomous peer-to-peer collaboration. DeAR is built on three mechanisms: (1) decentralized capability grounding for query-dependent agent specialization, (2) thought map navigation for targeted peer interactions, and (3) topology update for adaptive error correction. Evaluations across 9 diverse multimodal reasoning and text-based QA benchmarks indicate that DeAR consistently outperforms recent baseline methods, validating that decentralized and adaptive collaboration among agents enhances accuracy in knowledge-intensive reasoning tasks. The source code will be available at https://open_upon_acceptance.

**现有智能体推理系统的结构性缺陷：**

- 当前主流的 Agentic Reasoning 系统（如 AutoGen、AgentVerse、DyLAN 等）几乎全部依赖 **中心化协作协议（Centralized Collaboration Protocol）**，即存在一个中央协调器（coordinator）或裁判节点（Judge Agent）来负责任务路由、角色分配和结果汇总。
- 这种中心化设计在复杂多模态查询场景下暴露出严重问题：
  - **路由瓶颈（Routing Bottleneck）**：所有中间结果必须经过中央节点聚合，该节点成为严重的信息传递和决策瓶颈；
  - **静态角色分配（Static Role Allocation）**：系统预设固定角色（如“视觉提取者”“数学专家”），但角色标签与实际能力之间缺乏可靠对应，导致能力幻觉与错误路由；
  - **错误传播与不可恢复性**：一旦某智能体产生幻觉结果，中央裁判会不加验证地聚合这些错误，且推理链断裂时往往需要整体重来，效率极低。
- 论文指出，真实世界中的复杂问题求解本质上是 **去中心化的**——跨学科专家之间并非等待中心管理者逐一指挥，而是自主进行点对点协商、自主组织以弥合知识差距。这种去中心化范式在智能体推理中尚未被充分探索。

**论文的核心主张：** 中心化系统的失败源于架构性缺陷（而非底层模型能力不足），因此需要从“中心控制”转向“自主点对点协作”。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 2.1 总体框架

DeAR 将系统定义为四元组：**S = (Q, A, C, K)**

- **Q**：查询（query）
- **A**：智能体集合（agents）
- **C**：协作倾向矩阵（Collaboration Propensity Matrix），维度 N×N，编码智能体之间的交互概率
- **K**：知识状态序列（knowledge states）

### 2.2 三大核心机制

**（1）去中心化能力锚定（Decentralized Capability Grounding）**

- **动机**：静态角色标签（如“数学智能体”）无法反映真实能力，导致中心协调者产生能力幻觉。
- **实现方式**：
  - 每个智能体 $a_i$ 不预设角色标签，而是依据其底层模型的官方技术报告/模型卡（$P_i$）中的**量化基准分数**（如 GSM8K、MMLU、TruthfulQA 等）建立能力档案：
    $$\tau_i = [\tau_i^{cr}, \tau_i^{ea}, \tau_i^{nc}, \tau_i^{fr}, \tau_i^{cm}]$$
    分别对应常识推理（commonsense reasoning）、解释能力（explanatory ability）、数值计算（numerical computation）、事实可靠性（factual reliability）和自然语言理解（natural language comprehension）。
  - 通过 **Softmax 归一化**将不同模型的原始分数映射到同一可比尺度上：
    $$\tau_i^d = \frac{\exp(s_i^d)}{\sum_{k=1}^{N}\exp(s_k^d)}$$
  - 收到查询 q 后，智能体动态地基于查询需求、自身技术报告和能力档案，生成**查询相关能力状态** $\tau_i(q)$，并以此条件化其知识生成过程：$K_i = \Theta_i(q|\tau_i(q))$。

**（2）思维图导航（Thought Map Navigation）——自组织协作**

- **动机**：消除中央路由器的全局线性路径决策，改为局部图遍历。
- **实现方式**：
  - 每个智能体 $a_i$ 计算对其他智能体的**协作倾向向量** $c_i$，基于查询对应的认知维度 d，通过温度缩放 Softmax 计算 $c_{i,j}$：
    $$c_{i,j} = \frac{\exp(\tau_j^d/T)}{\sum_{k \neq i}\exp(\tau_k^d/T)}$$
  - 自循环被禁止：$c_{i,i} = 0$。
  - 汇总所有向量形成协作倾向矩阵 C（一个有向加权邻接矩阵）。
  - **导航过程**：从随机选中的初始智能体开始，当前智能体作为局部导航者，选择使增量效用最大的未访问智能体作为下一节点：
    $$a_{i+1} = \arg\max_{a_j \in A} u_i(a_j)$$
  - 被选中的智能体基于查询和此前累积的全部知识上下文生成新的知识片段，形成渐进增强的推理链。
  - **动态终止**：当所有未访问智能体的协作倾向低于阈值或所有智能体均已访问时，终止节点直接基于完整累积上下文生成最终答案。

**（3）拓扑更新（Topology Update）——渐进式精化**

- **动机**：解决中心化系统中“推理链断裂即整体重来”的低效问题。
- **实现方式**：
  - 由终端智能体（而非外部裁判）验证最终上下文是否匹配查询需求；若不匹配则触发拒绝。
  - 采用**局部化渐进回溯**策略：初始只将末端的失败边加入 $E_{fail}$，若局部选择耗尽则逐步向前扩展至更早的边。
  - 对失败边施加衰减因子 α 更新协作矩阵：
    $$c_{i,j} = \begin{cases} \alpha \cdot c_{i,j}, & (a_i \rightarrow a_j) \in E_{fail} \\ c_{i,j}, & \text{otherwise} \end{cases}$$
  - 更新后智能体在调整后的拓扑上重新导航，通过反复探索-回溯-精化，渐进收敛到有效推理路径。

### 2.3 核心思想的本质

- **从中央路由 → 局部图遍历**：协作矩阵相当于动态邻接矩阵，由每个智能体基于当前查询上下文局部计算，而非全局统一规划。
- **从静态角色 → 动态能力匹配**：能力评估来源于可验证的量化基准，且随查询动态调整。
- **从整体重来 → 渐进修正**：利用拓扑地图保留已取得的推理进展，仅修剪失败路径。

## 6. 论文的主要结论与发现

1. **去中心化架构优于中心化架构**：DeAR 在所有 4 个多模态基准上取得最高分（MMMU 55.58、MathVista 59.41、ChartQA 89.43、ScienceQA 62.45），显著超越 AutoGen、AgentVerse、DyLAN 等中心化多智能体框架。
2. **架构收益独立于参数量**：DeAR 以约 28B 总参数胜过 Qwen2-VL-72B（MathVista 上高出 18.07 分），证明系统性能提升来自去中心化协作设计而非参数堆叠。
3. **消融验证核心贡献**：
   - 固定角色路由导致 MMMU 下降 5.76 分（55.58 → 49.82）；
   - 去除拓扑更新导致 MMMU 下降 2.37 分（55.58 → 53.21）；
   - 证明优势来自**去中心化导航 + 自适应纠错**，而非简单模型集成。
4. **思维图导航带来显著增益**：在 MathVista 上整体提升 7.73 分（51.68 → 59.41），其中统计推理（STA）从 62.9 提升至 80.9、逻辑推理（LOG）从 19.6 提升至 31.0，说明自适应导航对复杂多步推理尤为重要。
5. **拓扑更新的普适有效性**：在全部 4 个多模态基准上均带来稳定性提升，有效减少多步推理错误累积。
6. **资源效率**：62.5% 的查询由少于 4 个智能体完成，表明动态激活避免了不必要的计算开销。
7. **衰减因子 α 在 [0.5, 0.8] 区间最优**：过小导致过度修正（路径不稳定），过大导致无效路径反复计算。
