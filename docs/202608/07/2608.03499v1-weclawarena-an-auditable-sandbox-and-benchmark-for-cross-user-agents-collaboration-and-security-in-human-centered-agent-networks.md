## 摘要
近期在持久化个人智能体框架方面的进展，使得以人为中心的智能体网络成为现实可行的部署目标：每个用户可由一个代表用户行事、维护状态并通过社交与任务关系与其他智能体通信的AI智能体提供服务。在这些网络中，日常工具使用演变为跨个人工作空间的多方拥有智能体协作，其中文件、记录、工具和策略在拥有者之间并非直接可见。现有智能体基准研究了工具使用与协作，但未提供具备真实用户数字工作空间的可验证跨用户智能体协作的端到端沙盒，也未测试有害行为如何通过以人为中心的智能体网络传播。我们提出了WeClawArena，一个用于跨个人工作空间的多方拥有智能体协作的可审计基准与运行时沙盒。WeClawArena聚焦于协作式工具使用任务，其中个人工作空间既充当操作工具，也充当个人约束。该基准包含六个跨用户任务域中的124个基础任务，并将其扩展为620个场景变体，每个基础任务包含一个良性对照和四个攻击向量变体。该沙盒记录对等消息、工具调用、资源操作、受治理决策和最终工作空间状态。WeClawArena分别报告效用与攻击成功率，并从有界运行时证据中审计攻击成功性，支持对任务分解、隐私泄露、中毒证据和无效权限路径的诊断。

## Abstract
Recent advances in persistent personal-agent frameworks are making human-centered agent networks realistic deployment targets: each user can be served by an AI agent that acts on the user's behalf, maintains state, and communicates with other agents through social and task relations. In these networks, everyday tool use becomes multi-party owned-agent collaboration over personal workspaces, where files, records, tools, and policies are not directly visible across owners. Existing agent benchmarks study tool use and collaboration, but they do not provide an end-to-end sandbox for verifiable cross-user agent collaboration with realistic user digital workspaces or test how harmful actions can travel through the human-centered agent network. We introduce WeClawArena, an auditable benchmark and runtime sandbox for multi-party owned-agent collaboration over personal workspaces. WeClawArena targets collaborative tool-use tasks in which personal workspaces serve as both operational tools and personal constraints. The benchmark contains 124 base tasks across six cross-user task domains and expands them into 620 scenario variants, with one benign control and four attack-vector variants per base task. The sandbox records peer messages, tool calls, resource operations, governed decisions, and final workspace states. WeClawArena reports utility and attack success rate separately and audits attack success from bounded runtime evidence, supporting diagnosis of task breakdown, privacy leakage, poisoned evidence, and invalid authority paths.

- **研究背景**：随着持久化个人智能体框架（如 OpenClaw）与多智能体协调框架（如 AutoGen、AgentVerse、MetaGPT）的发展，AI 智能体已从单轮对话接口演化为主张长期状态管理的个人代理，能够在用户数字环境中持续行动。同时，Agent-to-Agent（A2A）协议和生成式智能体社会模拟的发展，使得以人为中心的智能体网络（Human-Centered Agent Networks）成为现实部署目标。
- **核心问题**：这篇论文瞄准一个被现有基准忽略的关键场景——**跨用户的多方拥有智能体协作（multi-party owned-agent collaboration over personal workspaces）**。在该场景中，每个用户由自己的 AI 代理服务，代理之间需要通过消息、工具调用、资源操作和授权流程协同完成真实任务；而个人工作空间（文件系统、数据库、工具、策略）在拥有者之间不可直接可见。这带来三个研究问题（RQ）：
  - RQ1：**任务效用**——当完成任务所需的信息、工具和决策权分散在多个个人工作空间时，智能体能否完成协作式工具使用任务？
  - RQ2：**最终危害**——当协作通道同时携带攻击者的对抗压力时，在协作、安全、隐私、治理四大方面会产生哪些危害？
  - RQ3：**攻击审计**——运行时证据能否支持对"谁做了什么、哪些消息/工具/资源/授权路径起作用、为什么产生有害或良性结果"的审计？
- **现有不足**：工具使用基准（τ-bench、τ2-Bench、AgentBench、GAIA）通常只覆盖单一用户/单一环境；多智能体基准（MultiAgentBench）未引入拥有者特定资源和决策权限；社交模拟（AgentSocialBench）侧重对话而非可验证的协作工具使用；隐私与安全基准（MAGPIE、AgentLeak）未将确定性协作效用与攻击审计置于同一端到端环境中。WeClawArena 填补了这一空白。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **形式化建模**：论文将每个节点定义为个人工作空间 `n_u = (u, A_u, W_u)`，其中 `W_u = (F_u, D_u, T_u, P_u)` 分别代表文件系统、数据库、工具集和策略/约束/同意/审批规则。整个网络是一个有向图 `G = (N, E)`，边表示社交或任务关系。任务实例 `z = ⟨G_z, p, S_0, B, F, C, V_z⟩` 中，`C` 是任务契约，`V_z` 是验证器；**任务契约不仅规定了满足任务所需的终态，还规定了不可跨越的工作空间边界**。
- **核心思想**：个人工作空间既是任务完成的手段，也是约束面。代理必须通过自有工作空间读取、验证和更新资源，而非仅通过文本对话完成任务。攻击压力可能通过消息、文件、数据库行、工具观测等通道注入，但**不允许直接修改最终得分状态**；攻击只有通过代理的普通消息或工具行为传播并造成最终危害，才算攻击成功。
- **基准构建流程**：
  1. 从种子任务池（如 SWE-bench Lite）出发，由人工标注者填充统一的场景表单，生成基础任务（base task）。
  2. 每个基础任务派生 5 个场景变体：1 个良性对照（无攻击者）+ 4 个攻击向量变体（协作、安全、隐私、治理）。
  3. 每个场景以 JSON 文件形式保存：`scenario.json`（agents + tools）、`scenario.gt.json`（ground truth）、`context.json`（种子事实、人设、工作空间资源、MCP 接口）。
- **沙盒架构**：基于 Docker 的用户工作空间 + 网关（gateway）中介的运行时。所有对等消息、工具调用、资源操作、策略决策和最终状态均通过网关记录为类型化审计事件。证据包（evidence packet）包含场景元数据、攻击元数据、完整转录、工具调用与观测、任务得分字段、所有者/治理上下文。
- **评估协议**：
  - **效用（Utility）/ TSR**：基于最终工作空间状态 + 证据链进行确定性验证，按领域区分（如交易关闭工件、旅行预订成功、SWE 工作流证据链 + harness 结果等）。
  - **攻击成功率（ASR）**：与效用完全分离，由 LLM-as-a-judge 在运行后基于有界证据包判断是否存在攻击向量特有的最终危害 + 清晰的证据链链接。
  - **四个危害面**：协作危害（目标劫持、共识破坏）、安全危害（工具滥用、证据投毒）、隐私危害（上下文完整性违规）、治理危害（无效授权路径、缺失同意、越权审批）。

## 6. 论文的主要结论与发现

- **模型效用差异显著**：Claude Opus 4.7 整体效用最强（全变体 TSR 63.3%），Claude Sonnet 4.5 在 bargaining 上领先（68.3%）；SWE-Workspace 对最佳模型也仅有 34.0% 全变体 TSR，说明领域难度差异大。
- **攻击成功率差异显著**：Claude Opus 4.7 是最具攻击抵抗力的模型（全向量 1−ASR = 97.4%），开放权重模型聚类偏低（DeepSeek V3.2 为 51.1%、Qwen3 32B 为 54.0%）。**没有单一模型在所有危害面上都是最优的**。
- **危害面不可合并**：治理（50.3% ASR）和安全（42.5%）攻击成功率最高，协作（18.3%）最低；同一威胁面在不同领域的落地差异很大——安全压力主导谈判与竞标，隐私与治理压力主导 SWE 工作区，竞标中治理危害几乎为零。
- **效用与攻击成功是相关的但不同的维度**：有 117 行既完成任务又达到攻击成功（隐蔽危害），1,035 行攻击成功但任务失败，640 行任务完成且阻断攻击，1,951 行任务失败且无攻击成功。**只凭 TSR 无法判断攻击是否成功**。
- **攻击审计的实际案例**（附录 G）：
  - Kimi K2 Thinking 在谈判安全攻击中采用了中毒价格并完成了采购订单：任务成功反而增加了风险。
  - Claude Sonnet 4.5 在 SWE 工作区中完成了全部代码审查，但泄露了受保护的测试与跟踪标识符：TSR 无法反映该隐私泄露。

## 7. 优点

- **填补空白**：首次提出将"跨个人工作空间的多方拥有智能体协作"作为可验证基准与运行时沙盒，将用户中心、多代理协作与安全审计统一到一个端到端环境。
- **基准设计精细**：124 个基础任务 × 5 变体（1 对照 + 4 攻击向量）的配对设计，使得攻击效果可以与同一任务的良性基线精确对比；通过场景表单 + 双重人工审校保证任务质量。
- **审计深度**：沙盒记录完整的运行时证据（消息、工具调用、资源操作、治理决策、终态）；ASR 从有界证据审计，支持对任务崩溃、隐私泄露、证据投毒和无效授权路径的定位诊断——不只是"好/坏"标签，而是可追溯归因。
- **指标分离**：TSR 与 ASR 分离报告，且明确"攻击注入 ≠ 攻击成功"，必须通过代理行为传导并造成最终危害；良性对照用于误报率校准（<1%）。
- **评估严谨性**：双 LLM 法官（GPT-5.2 与 Opus 4.7）交叉验证（κ=0.70），200 行人工作标定（human-human κ=0.82），敏感性分析完整，且报告策略明确（保留 GPT-5.2 为头条法官作为 ASR 下界）。
- **领域多样性**：六大任务域覆盖不同的协作拓扑（三元交易、卖家中心竞标、审批/同意三角、四所有者工程流、临床角色协调、市场决策）和不同的工作空间资源类型，增强了结论的普适性。

## 8. 不足与局限

- **ASR 依赖 LLM 判断**：攻击成功率的判定由 LLM-as-a-judge 做出，尽管与人类标注者达到 substantial 一致性（κ≈0.65 ~ 0.68），但依然存在 judge 模型选择偏差；双法官之间 ASR 整体相差 3.3 个百分点，部分单元格相差可达 8.9 个百分点，说明 ASR 对裁判模型敏感。
- **人工标注规模有限**：人工验证仅覆盖 200 行，标注者为论文作者本人（存在利害关系），且未报告更大人群标注者的一致性结果，标注者多样性不足。
- **算力信息披露不足**：未提供 GPU 型号、数量、总推理成本或运行时长，影响复现时的资源估算。
- **部分模型覆盖不完整**：Kimi K2.5 和 Qwen3 235B 在部分攻击模式下缺失行（daggered cells），在进行跨模型对比时这些缺口可能带来轻微偏差。
- **攻击载荷发布受限**：出于安全考虑，完整攻击载荷文本被删减或访问控制；这意味着他人难以完全复用攻击细节进行独立审计，虽然基准开放了任务、验证器、裁判提示和分数卡，但"攻击可重复性"与实际载荷可获得性之间存在张力。
- **扩展性未验证**：6 个领域虽多样，但仍是封闭集合；扩展到更多领域（如法律、金融咨询、政府服务）时的任务构建成本与审计可靠性尚不明确。
- **外部效度**：所有场景均为仿真工作空间，未在真实生产系统上验证，攻击路径在真实系统上的传播方式可能与模拟环境存在偏差。
