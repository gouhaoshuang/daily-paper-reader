## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）正在迅速普及，但其异构的执行轨迹为跨方法的评估提供了共同基础。仅关注结果的基准测试丢弃了协作信息，而LLM作为评判者的评估需要额外的、依赖模型的推理，并且可能因LLM和评分标准的不同而有所差异。我们引入了一个可泛化的评估框架，将原生MAS轨迹映射到统一协作图的共享空间中，使得不同方法能在相同的表示、参考集和指标面板下进行评估。候选图与查询特定的参考森林进行比较。每个森林是基准测试提供的已验证成功图的集合：它记录了代表性MAS方法完成任务的各种方式，而不是规定唯一的最优过程。将该框架实例化为ForestBench，我们从七个公共数据集中筛选出844个需要协作的查询，为每个查询预计算十个成功的以目标为条件的参考图，并评估六个代表性的MAS框架。受控的骨干网络、参考构建和扰动研究测试了评估的稳定性和范围。一旦基准森林构建完成，ForestBench可在毫秒内对轨迹进行评分，无需进一步的LLM推断，为比较不同的MAS协作轨迹提供了可复用的结构基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于大型语言模型（LLM）的多智能体系统（MAS）已成为复杂推理、软件工程和科学工作流的重要设计范式。大量新框架（固定流水线、动态角色分配、自组织群体等）以空前速度涌现，但评估与比较速度远远跟不上框架发展速度。
- **核心矛盾**：异构 MAS 框架的执行轨迹缺乏统一的横向比较基础——
  - **结果型基准**（如 GSM8K、MMLU、HumanEval）只评分最终答案，完全丢弃了 MAS 最核心的"协作过程"；
  - **LLM-as-Judge 评估**需要额外的、依赖模型和评分标准的推理，成本高、可复现性差，且不同 LLM 和 rubric 会产生不同结果；
  - 原生轨迹绑定于各框架特有的事件模式、角色词汇和通信协议，无法直接比较。
- **核心主张**：需要一种**可泛化的统一表示**（图结构），将不同 MAS 的执行"归一化"到同一结构空间中，在固定参考集和指标面板下进行确定性、可复现的比较。图结构能够保留"谁贡献了什么、谁消费了谁的输出、信息如何流动"等关键协作信息，同时去除框架特定的日志约定。
- **森林隐喻**：同一任务可通过辩论、规划者-专家流水线、对等群体等不同成功范式完成。若任选一个作为"金标准流程"会偏袒特定协调范式，因此用"参考森林"（多个已验证成功图）而非"单棵参考树"来保留成功协作的多样性。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 图抽象（Graph Abstraction）
- 将每次 MAS 执行轨迹 τ 投影为统一协作图：**G(τ) = (V, E, φ)**
  - V：每个原子动作对应一个节点；
  - E：动作间的信息传递对应一条有向边；
  - φ：为节点标注发出智能体、规范化角色 r ∈ R（来自共享角色词汇表）及动作文本内容。
- 该图为**有向无环图（DAG）**：每个原子动作有唯一时间戳，动作只能消费已发出的信息，故边严格向前，不会成环。
- 投影是有损的：丢弃框架特有的运行时状态和精确时钟交错，但保留角色、动作和信息流依赖。这种不变性使不同框架的原生轨迹在结构上可比较。

### 2.2 参考森林（Reference Forest）
- 每个已验证成功的协作结构作为一棵"参考树"（实际为 DAG），同一查询的多棵结构不同的树共同构成**参考森林 F(q) = {(G_k, q_k)}**（k=1,...,K(q)）。
- 每棵树来自代表性协作范式并被验证能正确完成任务；森林是基准发布的资产，非唯一金标准，也不枚举所有有效解法。
- 权重 q_k 综合验证正确性、结构简洁性和 token 成本，不代表普适过程质量标签。

### 2.3 评估指标
- **成对图相似度**：sim(G, G') = α·s_node + β·s_edge + γ·s_topo，默认权重 (α, β, γ) = (0.4, 0.4, 0.2)
  - s_node：规范化角色多重集的 Jaccard 相似度；
  - s_edge：角色类型化边指纹集 (r_u, r_v) 的 Jaccard 相似度；
  - s_topo：基于节点数和边数 min/max 比值的拓扑规模匹配项。
  - 基于规范化角色而非原始智能体 ID，使指标对智能体重命名和独立动作排列不变。
- **Forest Match（核心指标）**：FM(G, F(q)) = Σ w_k·sim(G, G_k) / Σ w_k，其中 w_k 为归一化参考权重。衡量候选图与整个森林中成功结构的整体对齐程度。
- **Best Similarity**：max_k sim(G, G_k)，衡量与最近一棵参考树的接近程度。
- **辅助指标面板**：
  - **Node Validity**：可被下游消费的动作中被至少一个下游动作消费的比例；
  - **Mean Uptake**：下游内容在语义上使用上游内容的边比例（基于嵌入余弦相似度）；
  - **Content Redundancy**：归一化后重复内容的占比；
  - **Tokens**：总 token 预算；**Efficiency**：每活跃智能体的图并行度。
- 所有指标均为图结构的确定性函数，**评估时无需额外 LLM 调用，毫秒级完成**。

### 2.4 查询筛选（Trace-Suitability Pipeline, TSP）
- 对每个查询沿三维度打分：深度 d（推理步骤数）、宽度 w（能力多样性，8 项能力的归一化香农熵）、可分解性 δ（能否自然划分为独立子任务）。
- 保留条件：d ≥ 5，w ≥ 0.5，δ ≥ 0.5（三元取"与"），排除太短、太窄或串行的任务，确保查询能引发有意义的协作结构差异。

### 2.5 评估新候选方法的流程
1. 运行候选方法并解析原生轨迹为统一事件流（agent_message、tool_call、decision）；
2. 投影为协作图，通过别名表将原始智能体名映射到共享角色词汇表；
3. 与预计算的参考森林比较，用指标面板评分。

## 6. 主要结论与发现

1. **准确率单独无法区分 MAS 方法**：6 个框架准确率仅差 0.038，但结构指标差异显著；单一标量无法刻画完整协作轨迹。
2. **森林结构信号具有区分力**：Forest Match 能揭示不同框架的协作形态与成功模式的匹配程度；领域特异性重要——Debate 在全局排名最低，但在 SWE-bench-V 上排名第一（评审-修订模式更匹配代码补丁任务）。
3. **结构面板暴露最终答案隐藏的差异**：如 AFlow 的高内容冗余（并行求解器重复）、Swarm 的节点未被下游消费等，均无法从准确率看出。
4. **参考森林构建方式稳健**：跨骨干、留出生成器、开放式构建、留出数据源的测试下，聚合排名基本保持；但个别轨迹级分数不具不变性。
5. **指标分工明确**：Forest Match 捕获参考相对结构，Content Redundancy 捕获重复内容（重复注入几乎不影响 FM 但被冗余指标检测）。
6. **框架与骨干效应可分离**：框架施加了跨骨干稳定的结构先验（跨骨干距离 0.171 < 骨干内距离 0.181）；编排增益取决于骨干能力——CoT 基线对比中，DeepSeek-V4 的平均增益为 −0.002、GPT-5.5 为 −0.039、Claude-S4.6 为 −0.069，说明"增加智能体"并非总是有益。
7. **失败模式可诊断**：失败分为"结构失败"（流程欠定义、角色缺失、固定模式不匹配）与"内容失败"（结构合理但求解器/验证器接受错误内容），对应不同的修复方向（任务自适应拓扑 vs. 更强验证聚合）。粗粒度诊断方向在三模型投票下高度一致（结构失败 93.5%、内容失败 81.2%）。
8. **成本优势显著**：一次性构建森林后，评估新轨迹零推理 token、毫秒级完成，相比 LLM-as-Judge 快约 2,900 倍。

## 7. 优点

- **统一表示创新**：将异构轨迹映射为统一协作图，从根本上解决了跨框架横向比较缺乏共同基础的问题；图抽象丢弃框架特有噪声，保留协作本质。
- **森林而非单树**：以"参考森林"替代单一金标准流程，尊重成功协作的多样性，避免偏袒任何特定协调范式，同时保持固定参考集的可复现性。
- **确定性、零成本评估**：所有指标是纯结构函数，评估阶段无需 LLM 调用，毫秒级完成，且参考森林作为开放资产可
