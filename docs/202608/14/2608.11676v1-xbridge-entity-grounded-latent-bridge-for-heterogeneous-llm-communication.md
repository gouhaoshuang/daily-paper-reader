## 摘要
异构多智能体LLM系统（其中智能体由不同模型家族驱动）通过减少冗余推理模式，可以优于同构配置。然而，现有的通信协议要么通过文本运作，丢弃发送方的内部表示，要么需要架构同质性才能进行潜在层面的传输。我们发现了跨架构通信中的实体锚定问题：跨注意力桥梁在不同LLM家族之间传输连续表示时，会出现稀有令牌压缩坍缩，导致实体身份在连续瓶颈中丢失（仅桥梁F1约30%）。我们提出了XBRIDGE，一种免解码通信协议，通过两种机制解决这一问题。词汇锚定映射（LAM）将发送方的原始上下文令牌映射到接收方的词汇表，提供离散的实体锚点。潜在富集桥梁（LEB）允许接收方查询发送方的隐藏状态以进行上下文富集。实体锚点通过接收方自身的自注意力将桥梁的上下文信号锚定到特定实体。在三个模型家族（Llama、Qwen和Mistral）、七个基准测试以及两个通信方向上，XBRIDGE在每个模型对的全部七个任务上均优于基于文本的通信，同时实现11倍更低的延迟；在同架构设置中，它还在七个任务中的六个上超过了KV共享基线。LEB仅需2.64亿个可训练参数（占接收方的3.8%），在小型平衡样本集上训练，并增加可忽略的推理开销。

## Abstract
Heterogeneous multi-agent LLM systems, where agents are powered by different model families, can outperform homogeneous configurations by reducing redundant reasoning patterns. Yet existing communication protocols either operate through text, discarding the sender's internal representations, or require architectural homogeneity for latent-level transfer. We identify the entity grounding problem in cross-architecture communication: cross-attention bridges that transfer continuous representations across different LLM families suffer from rare-token compression collapse, where entity identity is lost in the continuous bottleneck (bridge-only F1 ~30%). We propose XBRIDGE, a decode-free communication protocol that addresses this through two mechanisms. Lexical Anchor Mapping (LAM) maps the sender's original context tokens to the receiver's vocabulary, providing discrete entity anchors. A Latent Enrichment Bridge (LEB) lets the receiver query the sender's hidden states for contextual enrichment. The entity anchors ground the bridge's contextual signals to specific entities through the receiver's own self-attention. Across three model families (Llama, Qwen, and Mistral), seven benchmarks, and both communication directions, XBRIDGE outperforms text-based communication on all seven tasks for each model pair while achieving 11x lower latency, and in a same-architecture setting it also exceeds a KV-sharing baseline on six of seven tasks. LEB requires only 264M trainable parameters (3.8% of the receiver), is trained on a small balanced sample set, and adds negligible inference overhead.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：多智能体LLM系统中，异构模型（不同家族）驱动的智能体可以通过减少冗余推理模式，优于同构配置。但异构模型之间的通信存在严重瓶颈：不同模型的 tokenizer、词表、隐藏空间、架构不兼容。
- **现有通信协议的问题**：
  - **文本通信（NLComm）**：架构无关，但需要自回归解码，延迟高，且将发送方内部状态压缩为文本摘要，丢失大量内部表示。
  - **潜在层通信（如KV共享、隐藏状态注入）**：通常假设架构同构（对齐隐状态维度、注意力布局、位置编码、tokenizer），难以用于异构模型。
  - **跨架构连续投影**：虽然可以学习连续映射，但**存在实体锚定问题**——连续桥梁能传递上下文信息，却无法可靠保留实体身份（如人名、数字、稀有token），导致“稀有token压缩坍缩”（bridge-only F1 仅约30%）。
- **核心挑战**：异构通信需要同时满足三点：**实体保真度**（恢复接收方词表中的实体身份）、**实体锚定**（将发送方上下文信号绑定到正确的接收方实体）、**表示兼容性**（不把发送方激活直接当作接收方激活）。
- **本文解决方案**：提出 **XBRIDGE**，一种免解码的双通道通信协议，将“离散实体身份”与“连续上下文增强”解耦，使异构LLM能够进行潜在层通信而不丢失实体信息。

## 2. 方法论（核心思想、关键技术细节）

- **总体框架**：发送方执行一次前向传播，产生上下文 token 序列 \(c_S\) 和最后层隐藏状态 \(H_S\)。接收方只持有问题，接收两个信号：
  - **LAM**（Lexical Anchor Mapping）提供离散实体锚点（来自 \(c_S\)）；
  - **LEB**（Latent Enrichment Bridge）提供连续上下文增强（来自 \(H_S\)）。
- **Lexical Anchor Mapping (LAM)**：
  - 将发送方上下文 token 映射到接收方词表（确定性、训练无关的 \(\phi: V_S \to V_R^*\)）。
  - 直接ID查找：若token表面字符串在两词表中都存在，则直接映射；否则用字符串回退（反tokenize后按接收方tokenizer重新切分），映射无损。
  - 映射后的接收方ID通过接收方冻结嵌入矩阵 \(E_R\) 转为嵌入，并前置到接收方问题输入，形成 \(x_R = [e_{ctx}; E_R(Q)]\)。
  - 不训练额外投影，保证锚嵌入与接收方原生输入在同一空间。
- **Latent Enrichment Bridge (LEB)**：
  - 在接收方第 6、13、20、27 层插入4个门控交叉注意力模块（共约264M参数，占接收方3.8%）。
  - 每个模块：接收方查询 \(Q^{(l)} = W_Q^{(l)} \cdot LN_R(h_R^{(l)})\)，发送方键 \(K^{(l)} = W_K^{(l)} \cdot LN_S(H_S)\)、值 \(V^{(l)} = W_V^{(l)} \cdot LN_S(H_S)\)，用缩放点积注意力得到 \(A^{(l)}\)。
  - 通过门控残差更新接收方隐状态：\(h_R'^{(l)} = h_R^{(l)} + \tanh(\alpha^{(l)}) \cdot A^{(l)}\)，门初始化 \(\alpha=1.0\)（比Flamingo的零初始化收敛更快）。
  - 投影矩阵处理维度不匹配，实现跨架构“翻译”。
- **实体锚定集成**：
  - LAM提供的实体锚进入接收方输入后，经过自注意力传播，使接收方各层隐状态携带实体位置和身份信息。
  - LEB模块使用这些隐状态作为查询，使交叉注意力聚焦于发送方中与当前实体相关的上下文位置。
  - 这样，LEB的上下文信号被“锚定”到具体实体，而不是漂浮在连续空间中。
- **训练**：发送方和接收方均冻结，只训练桥模块。采用标准 next-token prediction 损失，在587个跨任务平衡样本上训练（不到10分钟）。

## 8. 缺点与局限性

- **未与连续隐空间方法直接对比**：文中虽然指出了 C2C、AC 等方法的假设限制，但没有在相同条件下实现它们进行实验比较。连续隐空间方法在处理实体时的失败虽有定性描述和桥接-only 的消融作为证据，但缺乏与现有连续桥接方法的直接基线对比。
- **训练依赖特定发送方-接收方对**：LEB 模块针对每个发送方-接收方对独立训练，不同对之间的桥不共享。虽然双 sender 实验展示了组合性，但扩展到 N 个异构模型的网格状通信时，需要 O(N²) 个桥，成本较高。
- **实体映射依赖词面字符串**：LAM 通过 token 表面字符串或反 tokenize 后重新切分进行映射，对于同形异义词、语义实体（如"苹果"指公司还是水果）无法消歧。实体身份仅靠词表面绑定，没有利用发送方的语义角色或指代消解信息。
- **评估数据规模有限**：每个 benchmark 仅使用约 100-200 个样本，且训练集也仅 587 个样本。虽然训练时间短是优点，但这些数据规模下统计显著性检验缺失，结果可能存在抽样波动。
- **仅使用 F1 作为主要指标**：F1 对实体匹配敏感，但无法评估生成文本的流畅性、逻辑连贯性或推理质量。对于多跳推理中的中间步骤质量，F1 不完全适用。
- **接收方需加载额外桥模块**：虽然参数量小（3.8%），但在部署时每对通信方向都需要额外的注意力模块和对应权重，对多智能体动态组网场景不够灵活。

## 9. 创新点

- **首次解耦实体身份与上下文增强的双通道通信范式**：将连续桥梁失败的根源——实体锚定——明确分离出 LAM 与 LEB 两条通道，分别处理"谁"（Who）和"如何推理"（How）的信息，概念清晰且工程上可落地。
- **免解码的异构模型潜在层通信协议**：XBRIDGE 不要求发送方生成任何文本 token，避免了自回归解码的延迟与信息压缩损失，同时又不要求模型架构同构，突破了 KVComm 等方法的同构假设。
- **基于词表映射而非学习的实体锚定机制**：LAM 完全免训练、确定性、无损，利用接收方冻结嵌入矩阵天然地使跨模型实体嵌入对齐到接收方语义空间，设计极其轻巧。
- **门控交叉注意力定位思想**：在接收方后续层多处注入发送方上下文，并通过 LAM 锚点引导注意力焦点，形成一种"先锚定、后增强"的潜在空间信息融合机制。

## 10. 个人思考与启示

- **"免解码"是异构通信的重要方向**：传统 NLComm 将通信成本前置到发送方解码，连续隐空间方法将成本转移到训练对齐。XBRIDGE 展示了一条折中路径——极小规模训练（<10 分钟）即可带来显著提升，说明异构模型之间的通信瓶颈主要在于实体身份异构，而非上下文语义异构。
- **实体身份是连续空间的"离散奇点"**：连续表示可以压缩语义和结构信息，但对稀有 token 的压缩是破坏性的。这提示在设计多模态或跨模型接口时，人为保留离散锚点可能比纯连续映射更可靠。
- **双向不对称设计值得推广**：XBRIDGE 中发送方"零负担"、接收方"轻负担"的设定符合多智能体场景中共享服务方与被服务方的关系，比传统对称通信更符合真实部署需求。
- **潜在改进空间**：LAM 的语义消歧是明显短板，未来可引入发送方的注意力分布来对多义实体消歧，或让 LAM 学习一个轻量 reranker 来选择最合适的词表映射；此外，桥在发送方规模变化时的泛化能力（文中 1.5B/7B/14B 实验）也值得深入探索。

**总结**：XBRIDGE 是一篇问题驱动、设计精巧、实验扎实的论文，它以实体锚定问题为切入点，提出了一种极具实用潜力的异构 LLM 通信协议，为多智能体系统中异构模型的协作提供了新思路，也为后续跨模型潜在空间对齐研究确立了新的评估维度和基准。
