## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常仅通过由任务级奖励驱动的黑盒优化来学习通信拓扑。虽然有效，但这种优化对于为什么选择特定的通信边几乎不提供洞察，使得难以识别负责成功协作的关键通信子图。为解决这一局限，我们提出了E2-Explainer，一个模型无关的框架，用于为任意拓扑生成器产生的通信拓扑提供可解释的解释。具体来说，我们将拓扑解释表述为一个因果归因问题，通过任务保留的边级证据识别紧凑的通信子图。我们使用一种格兰杰风格的目标函数来获得这一证据，该目标函数衡量遮蔽每个通信通道如何改变任务结果和最终响应的稳定性。然后将得到的预算子图提炼成一个摊销解释器，使得在部署时无需重复的边级评估即可进行高效的事后解释。在多个推理和编码基准上的大量实验表明，E2-Explainer能够识别保持成功协作的关键通信子图。这些子图还可以直接执行以修剪冗余的通信边，在保持竞争性任务性能的同时显著降低通信成本。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

### 1. 核心问题与整体含义

- **研究背景**：基于LLM的多智能体系统（MAS）的协作性能高度依赖智能体之间的通信拓扑结构。已有工作分为两类：**剪枝式**（从现有工作流中移除冗余链接）和**生成式**（任务条件化的图生成），但这两类方法都通过黑盒优化（仅由任务级奖励驱动）来学习拓扑。
- **核心问题**：
  - 黑盒优化**缺乏可解释性**，无法回答"为什么选择某条通信边"。
  - 生成式拓扑（如G-Designer）仍含大量冗余或仅与成功相关而非因果相关的通信边，随机掩蔽测试显示大多数随机剪枝会降低性能，说明任务保留的紧凑子图存在但**难以通过随机剪枝发现**。
- **整体含义**：本文提出**E2-Explainer**，一个模型无关的事后解释框架，将拓扑解释形式化为**因果归因问题**，识别保持协作成功的最小因果子图，同时该子图可直接执行以降低通信成本。

### 2. 方法论

#### 核心思想
将**Granger因果性**从个体通信边扩展到局部通信子结构：若某通信边传递的信息能提升MAS协作性能，则该边对协作具有因果重要性。基于此构建"边移除干预→测量任务信号变化"的因果归因，并蒸馏为摊销解释器实现高效部署。

#### 关键技术细节

**（1）边级Granger风格因果归因**
- **任务级因果贡献**：对每条边e=(u,v)，构造干预图G-e=G\{e}并重新执行MAS，定义
  Δtask_e = Q(x,G) − Q(x,G−e)，取非负部分 u_task_e = max(0, Δtask_e)
- **辅助语义信号**：当任务信号稀疏时，使用结果级语义熵（M=5次随机执行，语义等价分组后计算熵）作为补充，定义
  u_sem_e = max(0, H̄(Y_G−e) − H̄(Y_G))
- **统一边效用**：u_e = clip_[0,1](α · ûtask_e + β · ûsem_e)，默认(α,β)=(0.8,0.2)，产生边的重要性排序πG

**（2）因果子图提取**
- 预算b=(ρE, ρV)指定边/节点剪枝比例，转化为保留数量kE(b)、kV(b)
- 按重要性排序选取TopK边：E⋆b = TopK(πG, kE(b))
- 执行**可执行性约束投影**Rvalid：只从原始边集中选边，不引入新连接，保留强制输入和最终聚合节点，移除与排除节点相连的边

**（3）摊销子图解释器**
- 用因果提取的子图作为监督，训练参数化解释器Fθ：(x,G,b) ↦ Ĥb
- 训练目标：边保留和节点保留的二元交叉熵损失 + 节点损失权重 + 权重衰减
- 测试时：一次性前向预测边/节点保留概率 → TopK解码 → Rvalid投影，无需任务标签和重复边干预

### 6. 主要结论与发现

- **通信成本大幅降低**：在4种拓扑优化器上，E2-Explainer减少加权Token消耗20.1%–25.6%，且在所有24个"优化器×数据集"组合中Token均下降。
- **任务精度保持或提升**：平均精度提升0.44–1.09个百分点不等；24个组合中16个精度提升、1个持平、7个下降。
- **强跨生成器迁移性**：仅用G-Designer图校准，直接迁移到ARG-Designer、OFA-MAS、AgentPrune仍有效，表明学到的是可复用的通信路径选择线索（而非记忆特定邻接模式），这一点在手工拓扑泛化实验中得到进一步验证。
- **跨智能体规模可迁移**：5-agent训练→6-agent测试，MMLU精度提升2.27点、HumanEval提升0.82点，同时Token减少10%–19%。
- **因果信号主导、语义熵补充**：因果信号是主要贡献来源，去除后MMLU精度下降3.92点；语义熵作为稀疏任务反馈的补充信号，两者结合最优。
- **不同预算的权衡关键**：边剪枝单独使用对精度影响小但Token节省有限（E75+N0仅省5.27%）；引入节点剪枝才能大幅降本，但过度剪枝（N40）会损害代码生成性能（HumanEval降低6.52点）。
- **冗余普遍存在但不随机**：OFA-MAS上也观察到与G-Designer类似的冗余现象，但大多数随机掩蔽会损害性能，说明因果信引导的剪枝是必要的。

### 7. 优点

- **模型无关性**：独立于任何拓扑生成器，可解释任意生成器输出的拓扑，且不需要访问生成器内部参数或优化状态。
- **因果机制明确**：任务级信号+语义熵双通道归因，将Granger因果性从可微图模型扩展到冻结LLM-MAS，提供了解释通信子图的理论依据。
- **蒸馏+摊销架构**：离线边级评估的成本被摊销到训练阶段，测试时只需一次前向传播即可预测子图，无需重复LLM执行和任务标签，实用性强。
- **子图可直接执行**：因果子图即为可运行的通信拓扑，直接充当剪枝工具，省去额外优化步骤。
- **解释与效率统一**：识别"为什么成功"与"如何更省"在同一框架内完成，同时回答可解释性和效率优化两个问题。
- **实验验证全面**：覆盖多数据集、多生成器、多预算、多智能体规模、多手工拓扑，并提供了细致的定性案例和执行轨迹分析。

### 8. 不足与局限

- **单边因果归因的局限**：只估计一阶条件贡献（在其余完整拓扑背景下），不枚举多边联合移除的组合，无法捕捉边间交互效应；最终子图效果以端到端评价为准。
- **独立采样引入偏差**：原图和掩蔽图的执行采用独立随机采样（而非配对种子），使因果归因包含采样噪声，定性案例中的精度变化不能严格归因于单条边的移除。
- **计算成本集中在离线阶段**：边掩蔽探测每边需M=5次MAS执行，校准阶段计算开销大；论文未量化该离线成本，可能限制实际应用中的扩展性。
- **单一骨干模型**：所有实验仅使用Qwen3-8B，未验证在其他LLM（如更强或更弱的模型）上的泛化性。
- **校准样本规模较小**：每数据集仅40个校准查询，对数据量敏感的数学数据集（如GSM8K、MultiArith）上精度改善不稳定，部分组合出现精度下降。
- **预算为预定义而非自适应**：E25+N20作为统一预算，在不同生成器和任务间不做自适应选择；跨生成器迁移时保持了同一预算，可能不是每个生成器的最优操作点。
- **手工拓扑实验未覆盖动态或分层复杂结构**：如带反馈环的拓扑、多轮对话图等；且篇幅限制导致部分实验细节（如解释器架构的超参数搜索）未充分展开。
- **模型无关性的边界**：虽然不依赖生成器内部参数，但仍需任务查询和角色信息作为输入，对完全未知的新型任务或角色体系可能需要重新校准。
