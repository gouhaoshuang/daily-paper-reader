## 摘要
基于大语言模型（LLM）的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常仅通过任务级奖励驱动的黑盒优化来学习通信拓扑。虽然有效，但这种优化几乎没有提供关于为何选择特定通信边的见解，使得识别负责成功协作的关键通信子图变得困难。为解决这一局限性，我们提出了E2-Explainer，一个模型无关的框架，用于为任意拓扑生成器产生的通信拓扑提供可解释的解释。具体来说，我们将拓扑解释表述为一个因果归因问题，该问题识别由任务保持的边级证据支持的紧凑通信子图。我们通过一种Granger风格的目标函数获得这一证据，该目标函数衡量屏蔽每个通信通道如何改变任务结果和最终响应的稳定性。然后将得到的预算子图蒸馏到一个摊销的解释器中，从而在部署时无需重复进行边级评估即可实现高效的事后解释。在多个推理和编码基准上的大量实验表明，E2-Explainer识别出保持成功协作的关键通信子图。这些子图也可以直接执行以修剪冗余的通信边，在保持竞争性任务性能的同时大幅降低通信成本。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

## 2. 论文提出的方法论

**核心思想：**

E2-Explainer的核心是将"哪条通信边重要"转化为"屏蔽该边是否显著恶化任务表现与响应稳定性"的因果干预问题。该思想与Granger因果一脉相承：若某条通道的信息能改善系统对任务结果的预测，则该通道对协作具有因果重要性。

**总体流程（四步）：**

1. **候选拓扑构建**：从任意拓扑生成器（G-Designer、ARG-Designer、OFA-MAS、AgentPrune等）获得候选通信图 G=(V,E)。
2. **Granger风格因果子图发现**：对每条活跃边执行单边移除干预，度量任务指标与语义熵变化，构建边级保留效用排序。
3. **蒸馏过程**：利用发现的因果子图作为监督信号，训练一个摊销解释器，学习"图→子图"的预算条件映射。
4. **测试时一次性预测**：对新拓扑，摊销解释器在前向传播中直接输出预算化的紧凑子图，无需边级评估。

**关键技术细节：**

**① 边级Granger式因果归因**

- 任务级因果贡献：

  \[
  \Delta^{task}_e = Q(x,G) - Q(x,G_{-e})
  \]

  其中 \(G_{-e}\) 表示移除边 e 后的干预图，Q为任务得分。正的 \(\Delta\) 表示该边有助于保持任务表现。

- 保留效用取非负部分：

  \[
  u^{task}_e = \max(0, \Delta^{task}_e)
  \]

- 辅助语义信号（弥补稀疏任务奖励）：使用语义熵衡量响应稳定性。对M次随机执行的结果进行语义等价分组，计算经验类熵 \(\bar{H}(Y)\)，定义：

  \[
  u^{sem}_e = \max(0, \bar{H}(Y_{G_{-e}}) - \bar{H}(Y_G))
  \]

  若屏蔽边后语义熵增大，说明该边有助于稳定最终响应。

- 统一边效用：

  \[
  u_e = \text{clip}_{[0,1]}(\alpha \cdot \tilde{u}^{task}_e + \beta \cdot \tilde{u}^{sem}_e)
  \]

  默认 \(\alpha=0.8, \beta=0.2\)，生成边的保留优先级排序 \(\pi_G\)。

**② 因果子图提取**

- 预算 \(b=(\rho_E,\rho_V)\) 指定边/节点修剪比例，转换为保留数量 \(k_E(b)\) 与 \(k_V(b)\)。
- 按保留效用选取 TopK 边：\(E^*_b = \text{TopK}(\pi_G, k_E(b))\)。
- 通过可执行性投影 \(R_{valid}\) 生成最终子图：保留强制输入与最终聚合智能体、删除被排除节点的关联边、丢弃不参与有效路径的可选节点。由于只从原始边集选择，DAG 结构天然保持无环性。
- 对多个预算构成子图家族 \(F^*(x,G)=\{H^*_b : b \in B\}\)，刻画效率与保真度之间的权衡曲线。

**③ 摊销解释器**

- 以（查询、候选图、预算、目标子图）四元组为监督，训练参数化解释器 F_θ 预测边/节点保留概率。
- 训练目标为边级与节点级的二值交叉熵损失：

  \[
  L = L_{edge} + \lambda_{node} L_{node} + \lambda_{wd} \|\theta\|_2^2
  \]

- 推理时通过 TopK 与有效性投影直接输出子图，**不需要任务标签、不需要边干预、不需要反复执行MAS**。

**模型无关性**：解释器不访问拓扑生成器的参数或优化内部状态，仅依据候选图、任务查询和智能体角色信息进行预测，因此可泛化到训练时未见的生成器。

## 6. 论文的主要结论与发现

1. **E2-Explainer 能识别保持协作功能的关键因果子图**，且这些子图可直接作为执行拓扑使用。
2. **通信成本显著降低**：在全部24个生成器-数据集组合上均实现token减少，加权在线token用量降低 **20.1%–25.6%**，其中G-Designer+E2-Explainer组合节省25.1%的token。
3. **任务性能保持甚至提升**：E2-Explainer 对 ARG-Designer、OFA-MAS、AgentPrune、G-Designer 分别提升平均准确率 0.44、0.53、0.58、1.09 个百分点；24个组合中16个精度提升、1个持平。
4. **跨生成器零训练迁移有效**：仅在 G-Designer 图上训练的解释器，可直接迁移至ARG-Designer、OFA-MAS、AgentPrune等未见生成器，表明学习到的通信保留线索具有通用性。
5. **跨智能体规模迁移可行**：5智能体训练直接应用于6智能体图，MMLU精度从79.43提升至81.70，HumanEval从89.26提升至90.08，同时token分别下降10.16%与19.38%。
6. **因果信号是主要驱动力，语义熵提供补充**：去除因果信号性能大幅下降（MMLU降低3.92点，HumanEval降低3.81点），但仅用因果信号不如两者结合，说明语义熵在稀疏奖励下提供额外密度化反馈。
7. **手工拓扑上亦有普适性**：在未见过的完整、随机、分层、链式、星形等固定拓扑上，30个组合中26个精度提升或持平且token全面下降。
8. **冗余并不意味任意剪枝安全**：随机掩码实验证明任务保持性子图罕见且难以通过随机搜索发现，凸出了因果引导的必要性。

## 7. 优点

1. **问题建模与视角新颖**：将通信拓扑解释形式化为Granger风格因果归因，为"为什么某些通信边重要"提供了个体干预层面的因果依据，而非仅停留在相关性分析。
2. **模型无关性和即插即用特性**：E2-Explainer独立于任何拓扑生成器，不访问其内部状态，可作为通用后处理模块配合任意已训练拓扑。
3. **可解释性与效率的统一**：识别出的子图既回答了"哪些通信路径支撑协作"的解释性问题，又可直接执行以节省token，实现"解释即优化"。
4. **摊销化的设计巧思**：通过离线边掩码评估的监督蒸馏到一个轻量解释器，部署时单次前向即可输出子图，规避了测试时重复因果评估的昂贵开销。
5. **双信号融合的因果评估**：任务信号（稀疏、精确）与语义熵（密集、稳定）互补，在不依赖密集任务反馈的场景下仍能提供可靠边效用估计。
6. **丰富的迁移验证**：跨生成器、跨智能体规模、跨手工拓扑的三重迁移实验，有效增强了方法泛化能力结论的可信度。
7. **定性分析深入**：提供4类正确/错误转换的完整执行轨迹，直观展示了子图修剪带来的信息传播变化，增进了对方法行为的理解。

## 8. 不足与局限

**实验覆盖方面：**

- **单骨干模型**：所有实验仅用Qwen3-8B，未验证方法在更大模型或其他模型家族上的适用性。
- **无方差报告**：报告3次运行平均但未给出方差/置信区间，难以判断改进是否具有统计显著性。
- **校准数据量小**：每数据集仅40条校准查询，可能对复杂任务的因果信号估计不够充分。
- **部分数据集上性能波动明显**：GSM8K、MultiArith、SVAMP上部分生成器出现精度下降（如ARG-Designer在GSM8K下降2.24点），论文对此未做深入归因。

**方法层面：**

- **仅估计一阶条件效应**：单个边的因果估计在其余拓扑保持完整的条件下获得，不枚举多边组合，忽略了边之间可能存在的协同或抵消效应。
- **独立采样反例**：原图和干预图分别独立采样（非配对随机种子），单案例的精度变化不能直接归因于被移除的边，定性分析存在一定的证据强度局限。
- **语义熵的计算成本**：每条边掩码需额外执行5次采样，离线监督构建成本相对较高（虽然摊销到训练阶段后测试期无此开销）。

**应用限制：**

- **预训练拓扑依赖**：E2-Explainer要求已有候选拓扑，无法从零生成拓扑；
- **预算需人工设定**：最优预算（默认E25+N20）需要预先扫描确定，且不同任务之间的最优预算存在差异；
- **未涉及对抗鲁棒性**：文本未讨论当部分智能体产生幻觉或恶意输出时，因果子图提取是否仍能保证协作质量。
