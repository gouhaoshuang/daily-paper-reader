## 摘要
由多模态大语言模型（MLLMs）驱动的移动GUI代理在人机智能方面展现出巨大潜力。然而，当前研究主要关注被动任务执行，缺乏对用户意图的全面理解-预测-执行过程，而这正是主动代理的核心需求。在本文中，我们提出了Act2Intention框架，通过整合理解、预测用户意图和执行决策来构建主动移动代理。首先，我们通过数据收集和验证生成构建了Act2Intention Bench，涵盖52个应用中的72,511个意图和超过700,000个动作，从而建立了首个通过连续意图-动作轨迹评估主动代理的基准。我们进一步开发了Act2Intention代理，通过面向主动的意图理解、个性化主动意图预测和经验引导的意图执行实现主动服务。实验结果表明，在相同代理框架下，针对意图理解、预测和执行，在Act2Intention Bench上进行监督微调相比未微调的对应模型分别获得了+32.0 Acc-S、+10.25 Acc-S和+6.9 SSR分的绝对提升。这一成功凸显了Act2Intention Bench的必要性和价值，它为开发和评估主动代理建立了标准化平台，从而为意图驱动的人机交互研究铺平了道路。

## Abstract
Mobile GUI Agents powered by multimodal large language models (MLLMs) show promise in human-computer intelligence. However, current research primarily focuses on reactive task execution while lacking a comprehensive understanding-prediction-execution process for user intentions, which are the core requirements of active agents. In this paper, we propose the Act2Intention framework that builds an active mobile agent by integrating understanding, predicting user intentions, and executing decisions. First, we construct the Act2Intention Bench through data collection and validated generation, comprising 72,511 intentions and over 700,000 actions across 52 apps, thereby establishing the first benchmark for evaluating proactive agents via continuous intention-action trajectories. We further develop the Act2Intention Agent, achieving proactive services through Proactive-oriented Intention Understanding, Personalized Proactive Intention Prediction, and Experience-guided Intention Execution. Experimental results show that supervised fine-tuning on Act2Intention Bench yields absolute improvements of +32.0 Acc-S, +10.25 Acc-S, and +6.9 SSR points over non-fine-tuned counterparts under the same agent framework for intention understanding, prediction, and execution, respectively. This success underscores the necessity and value of the Act2Intention Bench, which establishes a standardized platform for developing and evaluating proactive agents and consequently paves the way for research on intention-driven human-computer interaction.

## 论文总结：Act2Intention

### 1. 核心问题与整体含义（研究动机与背景）

- **现状**：当前移动 GUI 代理（Mobile GUI Agents）主要由多模态大语言模型（MLLMs）驱动，但大多仅作为"反应式执行者"——依靠用户的明确文本或语音指令来执行任务（L1 层面）。
- **核心缺口**：真实场景中，用户往往不会明确表达意图，而现有研究缺乏对用户意图的"理解→预测→执行"连续认知建模，这正是主动代理（Proactive Agent）的核心需求。
- **研究目标**：本文提出 Act2Intention 框架，通过从原始 GUI 动作流中推断用户意图、基于历史轨迹和用户画像预测未来意图，并在用户确认后执行意图，推动移动代理从"被动响应"向"主动服务"转变。

### 2. 方法论：核心思想、关键技术细节与流程

**整体范式：理解（Understanding）→ 预测（Prediction）→ 执行（Execution）**

**(1) Act2Intention Bench 数据构建**
- **数据来源**：90 名匿名参与者的真实手机使用日志（2024.3.1–4.29），包含时间戳、前台应用/活动、截图、动作类型及参数、用户填写的意图描述。
- **三个子集**：
  - **RR（Real-persona-to-Real-trajectory）**：真实行为轨迹 + 从同一用户历史行为推断出的真实画像；
  - **RG（Real-persona-to-Generated-trajectory）**：基于真实画像生成新的意图-动作轨迹；
  - **GG（Generated-persona-to-Generated-trajectory）**：基于生成画像进一步扩展行为多样性。
- **意图生成**：采用 Deepseek-R1，通过 Text-to-Persona 从 90 名用户的真实意图轨迹生成行为画像，再用 Persona-to-Persona 扩展 100 个画像；随后结合场景和画像迭代生成连续意图链。
- **动作轨迹生成**：并行部署多个 Android 模拟器，用 UI-TARS-1.5-7B 作为执行器，逐步生成对应每个意图的 GUI 动作轨迹。
- **两步质量验证**：
  - ① 意图过滤：从合成意图序列重建画像，与原画像计算余弦语义相似度，低于 0.7 则剔除（保留率 92.63%）；
  - ② 动作过滤：由 Deepseek-R1 根据意图、动作元数据和终止截图判断目标是否达成（保留率 87.03%）。
- **最终规模**：360 个画像、72,511 个意图、705,366 个动作、覆盖 52 个应用。

**(2) Act2Intention Agent 三大模块**
- **意图理解（Proactive-oriented Intention Understanding）**：
  - 动作描述：VLM 依据动作前后的截图和上下文生成标准化描述（格式：`[On/In] [App/Activity], [Action], to [Purpose]`），公式为 `d_t = f(d_t | o_t, a_t, o_{t+1})`；
  - 会话分割：将动作描述序列分割为不同意图段，`∪{p_i,...,q_i} = f({d_1,...,d_M})`；
  - 意图理解：对每个意图段生成自然语言意图描述 `I_{1:m} = f_φ(τ_des_{1:m})`。
- **意图预测（Personalized Proactive Intention Prediction）**：基于历史意图序列、当前时间和用户画像预测潜在意图 `Î_{t+1} = f_θ(I_{1:t}, T, P)`。
- **意图执行（Experience-guided Intention Execution）**：利用 all-MiniLM-L6-v2 对意图进行嵌入，检索历史相似"意图-动作"轨迹作为经验指导，由 GUI 代理迭代执行 `a_{t+1} = f_π(I, h_{t-1}, o_t, τ*)`。

### 3. 实验设计：数据集、Benchmark 与对比方法

- **Benchmark 划分**：训练集（RR/RG/GG 剩余数据）、ID 测试集（80 名用户各取最后 20%）、OOD 测试集（10 名随机用户数据），测试数据全部来自 RR 子集。
- **评估任务与指标**：
  - 意图理解：Acc-G（分组准确率）、Acc-S（语义余弦相似度）、BLEU-4；
  - 意图预测：Acc-C（类别准确率）、Acc-S、BLEU-4；
  - 意图执行：SSR（步骤成功率）、SR（端到端任务成功率）。
- **对比方法**：
  - 闭源模型：GPT-3.5-turbo、GPT-4o-mini、GPT-4o、Claude-3.5-haiku/sonnet、Qwen-max、Gemini-1.5-pro；
  - 开源模型（LoRA 微调）：Qwen-2.5-7B、Deepseek-7B、Mistral-7B、Llama-3.1-8B；
  - 执行器：UI-TARS-2B/7B-SFT、GUI-R1-3B、CogAgent-9B。
- **消融与深入实验**：
  - 动作描述 VLM 选择（GPT-4o、Gemini-1.5-pro、Qwen-VL-Max）对下游理解的影响；
  - 有无理解模块对预测的影响；
  - 有无经验引导对执行的影响；
  - 有无画像（persona）对预测的影响；
  - 不同训练数据组合（RR/RG/GG/RR+RG+GG）的影响；
  - 意图轨迹长度的影响（理解 1–10、预测 10–50）；
  - 置信度回退机制的端到端评估（阈值 0.60/0.80）；
  - 人工真实性评估（10 名标注员、3 子集各 30 段、5 点 Likert 量表）；
  - 正确分割下的语义误差分析（100 条轨迹）。

- **实验数量**：较为丰富，包括主实验（3 大任务 × 多模型）、7 类消融实验、ID/OOD 泛化对比、人工评估、错误分析、端到端评估，整体覆盖面较广。
- **充分性与客观性**：

### 6. 主要结论与发现

- **微调带来显著提升**：在 Act2Intention Bench 上 SFT 后，意图理解、预测、执行分别较未微调基线提升 +32.0 Acc-S、+10.25 Acc-S、+6.9 SSR。
- **意图理解**：Qwen-2.5-7B-SFT 的 Acc-G 从 12.14% 提升至 100%，Acc-S 从 0.24 提升至 0.49；但正确分割不保证精确语义描述（Acc-S 上限约 0.5）。
- **意图预测**：LLaMA-3.1-8B-SFT 取得最优 Acc-C（54.2%）和 BLEU-4（34.95），超过更大规模的闭源模型。
- **意图执行**：经验引导可将 UI-TARS-2B-SFT 的 SSR 提升 +9.9（35.6→45.5），说明相关历史轨迹能有效弥补小模型的任务分解能力不足。
- **端到端性能仍有瓶颈**：最优端到端 SR 仅 22.7%；当使用真实意图（GT）时提升至 47.6%，说明意图预测精度和长序列 GUI 执行鲁棒性是两个主要瓶颈。
- **数据子集互补**：RR+RG+GG 组合效果最佳，体现真实数据与合成数据的互补性。
- **画像的作用有限但明确**：persona 信息主要改善类别预测（Acc-C），对语义细节（Acc-S）提升不显著。

### 7. 优点

- **范式创新**：首次系统提出主动移动代理的"理解→预测→执行"三阶段认知架构，弥补了现有研究仅关注反应式执行的空白。
- **基准价值**：Act2Intention Bench 是首个包含连续"意图-动作"轨迹的移动端基准，规模大（72.5K 意图、70 万+动作、52 应用、360 画像），支持个性化连续意图建模，并包含 OOD 测试划分。
- **数据质量保障**：两步验证（画像一致性 + 动作完成度）显著提升合成数据可靠性，保留率统计透明。
- **实验设计系统**：多模型、多指标、多维度评估，涵盖消融/泛化/鲁棒性/人工评估，结论可信度较高。
- **开源开放**：代码和基准数据已开源（npuNancy/Act2Intention）。

### 8. 不足与局限

- **预测与执行是短板**：端到端 SR 仅 22.7%，意图预测语义精度（Acc-S≈0.4）和长轨迹执行鲁棒性均有较大提升空间。
- **缺少介入时机建模**：当前框架只做"预测什么"（what），未建模"何时打扰用户"（when），基准中未包含 opportune-moment 任务。
- **用户中心评估缺失**：未开展真实用户研究，无法验证建议的有用性、及时性与非侵入性；作者承认这是未来工作。
- **数据多样性有限**：仅 90 名匿名参与者、52 个应用，且因隐私协议无法获取人口统计信息，可能存在选择偏差；合成数据可能带有 LLM 的理想化/刻板模式。
- **OOD 泛化下降**：SFT 模型在 OOD 测试集上性能下降明显（如 LLM-3.1-8B-SFT 的 Acc-G 下降 12.73），对新应用、新界面布局的适应能力有待提升。
- **隐私与部署效率**：实际部署涉及敏感截图和个人使用历史，现有大型模型方案的延迟与能耗未在真实设备端评估；数据脱敏、联邦学习、模型压缩等方向尚待探索。
- **评估指标局限**：SSR 采用保守的逐步精确匹配，对功能等价的不同操作路径会产生误判；部分基准指标（如 BLEU-4）对语义等价表达的区分度有限。
