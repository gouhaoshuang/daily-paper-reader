## 摘要
自主机器人日益依赖边缘计算来卸载计算密集型的感知任务，同时通过5G网络保持实时运行。然而，传统的基准标记检测流程在高效任务划分方面提供的可能性有限，使其不适合通信感知的边缘部署。本文提出了一种用于5G边缘SLAM中基准标记处理的语义分割推理框架。一个受DeepTag启发的卷积神经网络在机器人和边缘服务器之间进行划分，其中中间特征表示作为面向任务的语义信息通过无线链路传输。该框架集成到基于ROS2的机器人架构中，并在真实的5G通信测试平台上进行表征。实验结果表明，该方法实现了准确的关键点估计，展示了对下游位姿估计的影响，并量化了与不同分割点相关的通信-计算权衡，为连接机器人系统中深度视觉感知的通信感知部署提供了实践见解。

## Abstract
Autonomous robots increasingly rely on edge computing to offload computationally intensive perception tasks while maintaining real-time operation over 5G networks. However, conventional fiducial marker detection pipelines provide limited opportunities for efficient task partitioning, making them poorly suited for communication-aware edge deployment. This paper proposes a semantic split inference framework for fiducial marker processing in 5G-enabled Edge SLAM. A DeepTag-inspired convolutional neural network is partitioned between the robot and the edge server, where intermediate feature representations serve as task-oriented semantic information transmitted over the wireless link. The framework is integrated into a ROS2-based robotic architecture and characterized over a real 5G communication testbed. Experimental results demonstrate accurate keypoint estimation, illustrate the impact on downstream pose estimation, and quantify the communication--computation trade-offs associated with different split points, providing practical insights for communication-aware deployment of deep visual perception in connected robotic systems.

## 2. 方法论：核心思想、关键技术细节、公式/算法流程

- **核心思想**：
  - 将基准标记感知管线抽象为有序处理块序列 \(P = \{P_1, P_2, \dots, P_N\}\)，整体功能表示为 \(F = f_N \circ f_{N-1} \circ \cdots \circ f_1\)。
  - 选取分割点 \(k\)，将管线划分为机器人端子集 \(P_{UGV} = \{P_1,\dots,P_k\}\) 和边缘端子集 \(P_{ES} = \{P_{k+1},\dots,P_N\}\)，从而 \(F = F_{ES} \circ F_{UGV}\)。
  - 机器人端生成中间表示 \(z = F_{UGV}(x)\) 并通过5G/ROS2传输至边缘，边缘端计算最终输出 \(Y = F_{ES}(z)\)。
  - 从语义通信视角将 \(z\) 视为**任务导向语义表示**，强调保留任务所需信息而非重建原始图像，其质量由分割点 \(k\) 联合决定。

- **网络架构（DeepTag实现）**：
  - 输入为256×256灰度ROI，预测16个图像空间关键点（4×4网格）。
  - 编码器为VGG风格5个卷积块，特征图尺寸逐步缩小：\(256\times256\times1 \to 128\times128\times32 \to 64\times64\times64 \to 32\times32\times128 \to 16\times16\times256 \to 8\times8\times256\)。
  - 回归头包含3×3卷积、自适应平均池化及两个全连接层（4096→512→32），总参数量约5.06M。
  - 每个编码器块对应一个候选分割点，输出特征图即为传输的中间表示 \(z\)。

- **损失函数与训练策略**：
  - 采用**空间加权Wing Loss**，对边缘区域权重降低，以减小边界关键点对PnP位姿估计的影响。基础损失公式为：
    \[
    \ell(\delta) = \begin{cases}
    w \ln\left(1 + \frac{|\delta|}{\epsilon}\right), & |\delta| < w \\
    |\delta| - C, & \text{otherwise}
    \end{cases}
    \]
    其中 \(w=10\)，\(\epsilon=2\)，\(C\) 为连续性常数。
  - 训练目标为加权平均损失：\(L = \frac{1}{KB}\sum_{b=1}^{B}\sum_{k=1}^{K} \omega_k^{(b)} \ell(\hat{k}_k^{(b)} - k_k^{(b)})\)，权重 \(\omega = \text{clamp}(d_{\text{edge}}/0.5, 0.3, 1.0)\)。
  - 采用两阶段训练：先在合成数据集上从头训练（Adam优化器，cosine annealing，70轮，batch size 32，初始学习率3×10⁻⁴），再在Gazebo Harmonic高保真渲染图像上微调（初始学习率5×10⁻⁵）。

- **通信—计算权衡**：端到端成本 \(T(k) = \gamma \cdot C(k) + t_0 + \beta \cdot S(k)\) 存在明确最优分割点，且最优位置随机器人端计算能力（γ）而变化：
  - γ≤2时，最优在更深层（传输256kB，省计算）；
  - γ≥4时，最优前移（更早分割以节省计算）。

- **实践启示**：自适应语义分割尤为必要，固定分割策略无法适应变化的计算与网络条件。
