## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）正在迅速普及，但其异构的执行轨迹无法为跨方法的评估提供共同基础。仅基于结果的基准测试丢弃了协作信息，而LLM作为评判员的评估则需要额外的、依赖于模型的推理，并且可能随LLM和评分标准的不同而变化。我们引入了一个可泛化的评估框架，将原生MAS轨迹映射到统一协作图的共享空间中，使不同方法能够在相同的表示、参考集和指标面板下进行评估。候选图与查询特定的参考森林进行比较。每个森林是基准提供的已验证成功图的集合：它记录了代表性MAS方法完成任务的多种方式，而不是规定唯一的最优过程。将该框架实例化为ForestBench，我们从七个公共数据集中筛选出844个需要协作的查询，为每个查询预计算十个成功的目标条件参考图，并评估六个代表性的MAS框架。受控的骨干网络、参考构建和扰动研究测试了评估的稳定性和范围。一旦基准森林构建完成，ForestBench可在毫秒内对轨迹进行评分，无需进一步的LLM推理，为比较不同MAS协作轨迹提供了可复用的结构基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

- **研究背景**：基于 LLM 的多智能体系统（MAS）正快速发展，涵盖固定流水线、动态角色分配和自组织群体等多种范式，但评估方法严重滞后于框架创新速度。
- **核心问题**：现有评估方式存在三大缺陷：
  - **结果型基准（Outcome-only）**：如 GSM8K、MMLU、HumanEval 等仅评分最终答案，完全丢弃了 MAS 赖以区别于单智能体的协作过程本身；
  - **原生轨迹异构**：不同框架的事件模式、角色词汇和通信协议各不相同，无法直接在过程层面进行横向比较；
  - **LLM-as-Judge**：需要额外的、依赖模型和评分标准的推理，成本高、可复现性差，且评判结果随 LLM 和 rubric 变化。
- **整体含义**：领域缺乏一个**通用的过程级表示**来规范化异构 MAS 执行轨迹，并在固定、可复现的评估空间中进行方法间的比较。论文提出以**图**为自然载体，构建统一协作图并进行结构化评估，填补了这一空白。

## 2. 论文提出的方法论

### 2.1 核心思想
将每个 MAS 执行轨迹投影为**统一的有向无环协作图（DAG）**，将异构、不可比的原始日志映射到同一结构空间；再通过查询特定的**参考森林（Reference Forest）** 而非单一参考树来评估候选图，保留成功协作的多样性。

### 2.2 图抽象（Graph Abstraction）
- 每个原子动作对应一个节点，每次信息传递对应一条有向边；节点带有动作文本、发起智能体和规范化角色标签。
- 图为 DAG：动作具有唯一时间戳且只能消费已产生的信息，因此边严格指向未来，不会形成环。
- 该投影是有损的：丢弃框架特定的运行时状态和精确时间交错，保留角色、动作和信息流依赖，使独立动作的不同交错产生相同图。

### 2.3 参考森林（Reference Forest）
- 每个已验证成功的协作结构作为一棵参考树；同查询可有多棵结构不同的有效树，共同组成参考森林。
- 参考树用从执行轨迹中提取的协作 DAG 表示，并携带一个连续质量分数（综合正确性、结构简洁性和 token 成本）。
- 参考森林是基准发布的资产：一旦构建完成，用户无需重新运行 LLM 或重建成功轨迹即可评估新方法。

### 2.4 评估指标（核心公式）
- **Pairwise 图相似度**（式 2–4）：
  - `sim(G, G') = α·s_node + β·s_edge + γ·s_topo`，默认权重 (0.4, 0.4, 0.2)；
  - `s_node`：规范化角色多重集的 Jaccard 相似度；`s_edge`：角色类型化边指纹（r_u, r_v）集合的 Jaccard 相似度；
  - `s_topo = ½[min(|V|,|V'|)/max(|V|,|V'|) + min(|E|,|E'|)/max(|E|,|E'|)]`，衡量图规模匹配度而不奖励冗长。
- **Forest Match**（式 5）：以参考图质量权重 `w_k` 归一化加权的平均相似度，衡量候选图与整个参考森林的总体对齐程度。
- **Best Similarity**：候选图与森林中最近参考树的最大相似度，衡量对任一成功模式的接近度。
- **辅助指标**：Accuracy（结果正确性）、Node Validity（被下游消费的动作比例）、Mean Uptake（下游语义上使用上游内容的边比例）、Content Redundancy（规范化内容哈希去重后的重复率）、Tokens（总 token 预算）、Efficiency（每活跃智能体的并行度）。

1. **准确率本身对方法的区分能力很弱**：6 个框架准确率仅跨 0.038（0.531~0.569），但 Forest Match 从 0.316（Debate）到 0.421（MAS-GPT），结构信号显著更具区分力。
2. **图指标面板能揭示最终答案隐藏的差异**：Debate 的 Best Similarity 最低（0.284）且 token 消耗最高（3,227），但冗余度最低、拓扑效率最高；AFlow 的内容冗余度（0.167）约为次高者的 3 倍；Swarm 是唯一 Node Validity < 1 的框架（0.968）。

6. **编排收益依赖骨干能力**：相对单智能体 CoT 基线，DeepSeek-V4 平均增益 −0.002、GPT-5.5 为 −0.039、Claude-S4.6 为 −0.069，添加智能体并非普遍有利。
7. **聚合对齐隐藏领域专长**：Debate 总体 Forest Match 最低但在 SWE-bench-V 上排名第一，全局排序需配合源码级分析使用。

## 7. 优点

- **表示统一、成本极低**：将异构轨迹映射到统一 DAG，评估完全确定性、毫秒级完成、零推理 token，且无需修改底层 MAS 系统。
- **森林理念先进**：以多棵已验证成功参考树构成森林，避免单模板对特定协调范式的偏袒，保留成功协作的多样性；参考森林作为可复用开源资产，下游用户零成本继承。
- **指标面板设计合理**：Forest Match + Best Similarity + 辅助指标（Node Validity、Mean Uptake、Content Redundancy、Tokens、Efficiency）形成结果、参考对齐、内容流、预算的多维刻画；不同指标各司其职（如扰动实验展示结构与冗余指标分工）。
- **鲁棒性验证充分**：系统性覆盖骨干、生成器、金答案条件化、数据源、权重、阈值等多维度敏感性分析，且大多保持排序一致。
- **诊断价值**：准确率 + Forest Match 的组合能定位失败是源于结构错配还是内容错误，为 MAS 调试提供了可操作方向。
- **诚实边界声明**：明确 Forest Match 是参考相对对齐而非普适质量标签，且与 LLM-as-Judge 的成本对比有清晰的实测数据支撑（0.7s vs 34min per 1k traces）。

## 8. 不足与局限

- **参考森林的构造依赖有限框架集合**：10 棵参考树仅由 6 个 MAS 框架生成，可能无法覆盖真实世界中所有成功协作模式；被遗漏的模式会使森林内对齐分数偏低，造成对某些新方法的系统性偏差。
- **金答案条件化可能引入结构偏差**：论文承认这仅是参考构造手段而非最优过程；条件化可能使参考图偏向"能到达正确答案"的结构，而非真实部署中的成功轨迹。
- **角色规范化依赖人工对应表**：跨框架语义相同角色的对齐依赖每框架的别名表；角色词汇覆盖不全时，节点/边相似度可能失真。
- **深度/宽度/可分解性筛选是启发式的**：TSP 不能证明保留的查询必须多智能体才能求解，也不能证明单智能体一定不能解决；阈值的理论基础较薄弱。
- **辅助指标存在局限**：Mean Uptake 依赖固定余弦阈值 θ_u，对文本语义表达的多样性（如同义改写）可能误判；Content Redundancy 基于规范化哈希，近似含义的重复无法捕获。
- **失败诊断的可靠性有限**：细粒度标签对 rubric 措辞敏感（Cohen's κ 低至 0.129），且 GPT-5.5 解析失败导致共享子集仅 138/300；论文建议只用于粗粒度维修方向，而非精确归因。
- **实验覆盖面的限制**：诊断实验仅采样 300 条轨迹，且代码/工具类任务占比相对较低（20.4%），对高度工具交互型 MAS 的结论外推需谨慎；**全文未报告 GPU 硬件和训练能耗**。
- **排序稳定不等于绝对分数准确**：跨骨干排序一致（τ=1.00）只在所测 3 个骨干上成立，不能保证对所有 LLM 骨干不变。
