## 摘要
无线网络正从以连接为中心的基础设施演变为智能化和个性化的服务平台。现有的无线智能仍然集中在网络侧优化，改进吞吐量、延迟和覆盖等目标。然而，除了网络性能之外，无线智能还依赖于用户通过应用上下文、移动习惯、服务成本、隐私偏好和长期使用行为所感知的体验。本文提出了WISPA，一种基于大语言模型（LLM）代理的无线智能自进化个人代理框架，用于自动化终端侧资源管理。为克服终端上的资源限制，WISPA将对延迟敏感的在线资源执行与离线LLM代理反思解耦。这样，轻量级在线执行器使用可解释的偏好参数做出确定性资源决策；而离线LLM代理分析终端侧轨迹，完善用户画像，并更新在线偏好参数以供后续决策。最后，我们在校园通勤路线上展示了WISPA在终端侧资源分配中的实际适用性和优势。数值结果表明，WISPA学习用户特定的连接风格，并根据偏好的变化调整接入决策。

## Abstract
Wireless networks are evolving from connectivity-oriented infrastructures into intelligent and personalized service platforms. Existing wireless intelligence remains centered on network-side optimization, improving objectives such as throughput, latency, and coverage. Nevertheless, besides network performance, wireless intelligence also depends on user-perceived experience via application context, mobility routine, service cost, privacy preference, and long-term usage behavior. This article proposes WISPA, a Wireless Intelligent Self-evolving Personal Agent framework for automated terminal-side resource management based on large language model (LLM)-based agent. To overcome the resource constraints on terminals, WISPA decouples the latency-sensitive online resource execution from offline LLM agent reflection. In this way, a lightweight online executor makes deterministic resource decisions using interpretable preference parameters; While an offline LLM agent analyzes terminal-side traces, refines user profiles, and updates online preference parameters for subsequent decisions. At last, we demonstrate the practical applicability and benefits of WISPA for terminal-side resource allocations on a campus commute route. Numerical results show that WISPA learns user-specific connection styles and adapts access decisions as preferences change.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
提出 **WISPA（Wireless Intelligent Self-evolving Personal Agent）** 框架，将终端侧资源管理解耦为两个阶段：
- **在线执行阶段**：轻量级、确定性的在线执行器（Online Executor）使用可解释的低维偏好参数进行实时资源选择，避免LLM参与实时决策。
- **离线反思阶段**：基于LLM的离线代理（Offline LLM Agent）在空闲时段（如夜间）分析已完成的服务记录，更新用户画像并修正偏好参数，以指导后续在线决策。

### 关键技术细节
1. **用户画像**：由低维偏好参数（平衡服务质量、能量负担、货币成本、隐私暴露之间的权衡）和反射记忆（Reflective Memory）组成，存储长期经验。
2. **在线执行器**：
   - 上下文适配器收集服务需求、无线测量、电池状态、移动信息、可行动作。
   - 选项评估器用简单模型预测每个候选选项的QoE和终端侧负担。
   - 决策执行器根据偏好参数化评分规则选择分数最高的选项，并实施服务地板检查（避免选择导致严重服务退化的选项）。
   - 记录缓冲区存储决策上下文、结果和低体验事件。
3. **离线反思模块**：
   - **观察模块**：将服务记录转换为周期级评估，诊断当前策略的不足。
   - **反思模块**：结合历史记忆，识别稳定的偏好线索、异常和重复模式，更新记忆。
   - **策略模块**：将离线理解转化为偏好参数的更新，更新量被限制在允许范围内，经过验证后部署。若更新无效或不安全，则保持原参数。

### 公式与算法流程（文字说明）
- 候选选项的体验分数 = 服务敏感QoE + 友好度分数（反映费用、能耗等负担） × 偏好参数。
- 在线选择：argmax(分数)，满足服务地板检查。
- 离线更新：LLM根据最近的服务记录和记忆，提出偏好参数调整（有界步长），经模拟器或规则验证后更新。

## 3. 实验设计：数据集/场景、基准、对比方法

### 场景与数据集
- **场景**：校园通勤路线，基于深圳大学布局构建，长约900m × 525m，含35栋建筑。学生从实验室步行至宿舍，使用文本交互、音乐流媒体和视频通话三种服务。
- **无线环境**：通过射线追踪生成路径级蜂窝RSRP轨迹（每0.2s采样）；WiFi覆盖划分强/中/弱三个区域。三类候选接入：WiFi、普通蜂窝SIM1、高保障蜂窝SIM2，各有不同的容量、时延、可靠性和友好度分数。
- **用户偏好**：三种预设用户画像：成本导向（Cost Oriented）、质量导向（Quality Oriented）、均衡型（Balanced）。

- **Baseline**：固定规则（强WiFi区域用WiFi，其余用普通蜂窝）。
- **Online Only**：与WISPA使用相同的在线执行器，但偏好参数保持不变（中性初始值），不进行离线反思。
- **WISPA**：完整在线+离线框架，经过10次使用-反思循环后评估最终策略。

## 6. 主要结论与发现

- WISPA能有效学习用户特定的连接风格，在10次迭代后，相比Online Only（偏好无关）提升平均体验分数：成本导向用户提高13.55%（0.767→0.871），质量导向用户提高11.25%（0.822→0.914），均衡型用户保持接近。

## 7. 优点

- **解耦设计创新**：将实时决策与LLM反思分离，既保证了在线执行的轻量、可解释、低延迟，又利用LLM的推理能力实现个性化长期优化。
