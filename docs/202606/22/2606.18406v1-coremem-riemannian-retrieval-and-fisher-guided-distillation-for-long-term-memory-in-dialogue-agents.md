## 摘要
个性化对话体需要持续的长期记忆以跨多会话保持连贯交互。然而，在消费级硬件（例如8 GB显存的边缘设备）上部署这些能力会带来严重的记忆与计算瓶颈。现有系统通常依赖各向同性余弦相似度进行检索，以及依赖启发式规则进行上下文压缩。这些方法缺乏统一的理论基础，常常在高维检索中遭遇中心点问题，并在压缩中遭遇句法碎片化。为克服这些限制，我们提出了CoreMem，一种由信息几何根本统一的资源高效边缘-云记忆架构。首先，黎曼检索用局部自适应的费舍尔-拉奥度量替代余弦匹配，通过马氏距离配合O(Ndr)伍德伯里加速有效惩罚中心点记忆以实现实时搜索。其次，费舍尔引导的离散分词蒸馏（FDTD）引入了分层句子到分词的压缩机制。它从费舍尔信息踪迹中推导敏感度得分，提供了原则性的压缩-KL权衡，并辅以显式句法结构保护。在LOCOMO和LongMemEval-S基准上评估，CoreMem实现了显著的准确率提升，在开放域（+4.51个百分点）和时间推理（+4.17个百分点）上获得了大幅增益。大量性能分析证实CoreMem在严格8 GB显存预算内无缝运行，成功弥合了资源受限边缘设备与对理论扎实、终身记忆体的需求之间的鸿沟。

## Abstract
Personalized dialogue agents require continuous long-term memory to maintain coherent interactions across multiple sessions. However, deploying these capabilities on consumer-grade hardware (e.g., 8 GB VRAM edge devices) introduces severe memory and compute bottlenecks. Existing systems typically rely on isotropic cosine similarity for retrieval and heuristic rules for context compression. These approaches lack a unified theoretical foundation, frequently suffering from the hubness problem in high-dimensional retrieval and syntactic fragmentation during compression. To overcome these limitations, we propose CoreMem, a resource-efficient edge-cloud memory architecture fundamentally unified by information geometry. First, Riemannian retrieval replaces cosine matching with a locally adaptive Fisher-Rao metric, effectively penalizing hub memories via Mahalanobis distance with O(Ndr) Woodbury acceleration for real-time search. Second, Fisher-guided discrete token distillation (FDTD) introduces a hierarchical sentence-to-token compression mechanism. It derives sensitivity scores from Fisher information traces, providing a principled compression-KL tradeoff augmented with explicit structural syntax protection. Evaluated on the LOCOMO and LongMemEval-S benchmarks, CoreMem achieves strong accuracy improvements, yielding substantial gains in Open-domain (+4.51 pp) and Temporal (+4.17 pp) reasoning. Extensive profiling confirms that CoreMem operates seamlessly within a strict 8 GB VRAM budget, successfully bridging the gap between resource-constrained edge devices and the demand for theoretically grounded, lifelong memory agents.

- **两大技术痛点**：
  - **高维检索中的中心点问题（hubness）**：少数“中心点”记忆主导最近邻列表，压制语义重要但几何上边缘的事实。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：用**信息几何**统一检索与压缩。将检索视为统计流形上的距离测量（使用逆协方差的Fisher-Rao度量），将压缩视为损失景观曲率的评估（使用对角Fisher信息矩阵）。
- **总体架构**：CoreMem（Curvature-oriented Riemannian Edge Memory）——边缘-云混合管道：
  - 本地边缘：嵌入模型 + 黎曼检索 + FDTD压缩器 → 将蒸馏后的上下文传输到云端。
  - 云端：商用LLM（如GPT-4o-mini）生成最终回答。
- **关键技术细节**：
  1. **黎曼检索（Riemannian Retrieval）**：
     - 使用**马氏距离**作为Fisher-Rao度量的具体形式，协方差矩阵通过低秩SVD修正对角估计：Σ ≈ U_r M_r U_r^T + D，其中D = diag(σ²+λ)，λ=10·mean(σ²)以控制条件数。
     - 利用**伍德伯里矩阵恒等式**（Woodbury identity）将协方差求逆复杂度从O(d³)降至O(N d r)，实现实时搜索。
     - **残差度量融合**：将余弦相似度与黎曼距离按权重α混合（α=0.5），分别处理“桥接事实”与“尾记忆”。
  2. **Fisher引导的离散令牌蒸馏（FDTD）**：
     - 通过一次反向传播计算每个令牌嵌入的Fisher信息迹：S(x_i)=‖∇_h_i L ⊙ h_i‖₂，作为令牌敏感度。
     - 理论保证：假设生成模型局部L-Lipschitz连续，按敏感度升序丢弃令牌可得到KL散度的上界（定理1）。
     - **分层压缩**：先分句，在长句子内保留首尾各3个令牌（保护主谓宾结构），再按句级平均分贪婪选择直至预算B。
     - **结构保护掩码**：对逻辑连接词（but, because等）乘以1.2×，标点/换行1.3–1.5×，数字/专有名词1.3–1.4×，历史轮次线性衰减（1.0→0.6），以及局部间隙自动填充（≤3字符）。
- **算法流程**（文字描述）：
  - 检索阶段：集中化记忆嵌入，计算SVD，选择秩r解释95%方差，预计算伍德伯里逆；对每个查询计算余弦与马氏得分，加权融合后取top-k。
  - 压缩阶段：冻结SLM，前向传播计算损失，单次反向传播获得∇_h_i L，计算敏感度，经平均池化和乘性结构掩码得到最终得分，按得分升序保留前B个令牌，并填充短间隙。

## 6. 主要结论与发现

1. **CoreMem-Fusion（α=0.5）在LOCOMO上取得最佳整体准确率**：Open-domain推理提升+4.51 pp，Temporal推理提升+4.17 pp（MiniLM-L6）。
2. **黎曼检索与余弦检索互补**：纯黎曼（α=0）在开放域和时间推理上表现优异，而余弦在多跳推理上更好；融合后总体最优。
3. **FDTD压缩在中等预算下优于启发式方法**：预算1000时条件准确率达0.9756，压缩比67.4%；但在极端低预算（≤500）下降超过简单截断。
4. **Riemannian检索对低质量嵌入尤其有效**：在MiniLM-L6（384维）上提升显著，在gte-Qwen2（1536维）上接近但不优于NaiveRAG，但后者占用显存过大。
5. **结构保护机制至关重要**：移除语法与关键词提升虽只略降ROUGE-L，但Judge准确率暴跌4.5 pp，证实逻辑连接词对推理的关键作用。
6. **ROUGE-L与LLM Judge相关性仅约r≈0.56**，表明需要语义评估。

## 7. 优点（方法或实验设计亮点）

- **理论统一性**：首次将检索与压缩置于信息几何框架下，检索用Fisher-Rao度量（马氏距离），压缩用Fisher信息迹，两者数学上同源。
- **实用高效**：伍德伯里加速使黎曼检索达到O(N d r)，本地推理仅需≤3.2 GB VRAM（gte-Qwen2 + Qwen3-0.6B），满足8 GB边缘设备约束。
- **原理性压缩保证**：提供KL散度上界（Theorem 1），使压缩不再靠试错。
- **结构保护机制设计巧妙**：通过乘性掩码保护句法元素，补偿Fisher对角近似的盲点。
- **实验全面**：覆盖多种推理类型、两种嵌入维度、多个SLM、多级预算，并有消融和案例分析。
- **公平控制**：压缩实验中所有方法使用相同检索上下文，端到端实验中控制嵌入模型一致。

## 8. 不足与局限

- **边缘部署限制**：当前使用0.6B–1B参数SLM，显存受限；记忆表示是扁平化的，无层次组织。
- **泛化与规模边界**：仅限英文基准，结构保护掩码对形态丰富语言（如俄语、汉语）的鲁棒性未知；Woodbury加速在记忆库>10万条时开销显著增大。
- **评估范围局限**：未进行检索与压缩的全因子端到端消融（由于API成本），两者交互效果未精确分离。
- **极端低预算性能下降**：当预算≤500令牌时，所有学习型压缩器不如简单截断，FDTD需进一步改进。
- **约8% VRAM预算边际**：gte-Qwen2-1.5B嵌入模型自身占用～5.9 GB，留给其他组件的空间较小，实际部署可能需权衡。
- **定性案例中黎曼检索可能受强主题中心点误导**（如车相关的“爱好”词汇重叠）——没有完美度量。
