## 摘要
在边缘服务器上部署轻量级大型语言模型（LLM）智能体可以降低延迟，并使智能体服务更接近用户，但资源受限的边缘模型在处理需要持久记忆、子目标跟踪和反思的长期任务时往往表现不佳。部署后对边缘模型进行微调成本高且难以在异构节点上扩展，而纯本地记忆则使智能体经验孤立，提示上下文不断增长。我们提出CoMIC，一种无需参数更新的云边协作记忆与见解流通框架。CoMIC采用“集中式反思、分散式执行”的设计：边缘智能体使用面向子目标的层次化记忆和选择性重扩相关历史记录在本地执行，而云端LLM评审者异步评估已完成轨迹，过滤可重用经验，并聚合以语义子目标标识符为键的跨智能体指导。在涵盖符号规划和文本交互的五项长期智能体任务中，CoMIC提升了弱边缘智能体的进度率和动作基础，并在不更新模型参数的情况下获得了依赖任务的成功率增益。

## Abstract
Deploying lightweight Large Language Model (LLM) agents on edge servers can reduce latency and move agentic services closer to users, but resource-constrained edge models often struggle with long-horizon tasks that require persistent memory, subgoal tracking, and reflection. Fine-tuning edge models after deployment is costly and difficult to scale across heterogeneous nodes, while purely local memory leaves agents with isolated experience and growing prompt context. We propose \textsc{CoMIC}, a parameter-update-free cloud-edge framework for Collaborative Memory and Insights Circulation. \textsc{CoMIC} follows a \textit{Centralized Reflection, Decentralized Execution} design: edge agents execute locally using subgoal-oriented hierarchical memory and selective re-expansion of relevant histories, while a cloud-side LLM critic asynchronously evaluates completed trajectories, filters reusable experience, and aggregates cross-agent guidance keyed by semantic subgoal identifiers. Across five long-horizon agent tasks spanning symbolic planning and text interaction, \textsc{CoMIC} improves progress rate and action grounding for weak edge agents and yields task-dependent success-rate gains without updating model parameters.

## 2. 方法论
### 2.1 核心思想
采用“集中式反思、分散式执行”（Centralized Reflection, Decentralized Execution）：
- **边缘执行**：代理使用子目标导向的层次化记忆（工作记忆保持当前细节，历史压缩为摘要）进行本地决策，并异步上传已完成的轨迹（不阻塞执行）。
- **云端反思**：云端LLM批评家独立评估每个轨迹，过滤可重用的经验（基于置信度评分），并通过语义子目标标识符聚合跨代理指导，形成全局指导（Global Guidance）下发给边缘。

### 2.2 关键技术细节
- **边缘层次记忆**：当前子目标保留详细动作-观测对；已完成子目标压缩为摘要。需要时可通过选择性重扩（selective re-expansion）恢复历史细节。
- **云端评论与准入**：评估轨迹后生成置信度评分 \( s_{\text{self}} \)，准入分数 \( s_{\text{adm}} = \text{clip}(s_{\text{self}} - \lambda_{\text{ctx}} I_{\text{retry}} - \lambda_{\text{short}} I_{\text{short}}) \)，满足阈值后存入经验库。
- **跨边缘聚合**：对同一子目标标识符 \( u \) 的多个经验进行汇总，生成综合指导（可重用汇总、洞察、建议、可信度分数）。
- **协作上下文组装**：边缘代理根据当前子目标标识符检索云端全局指导，与本地历史一起组装成决策提示 \( P_{t+1} = \mathcal{A}(g, g_{t+1}, o_{t+1}, H_{t+1}, G(u_{t+1})) \)。

### 2.3 算法流程（文字说明）
1. 边缘代理分解任务为子目标序列，为当前子目标执行动作。
2. 完成一个子目标后，异步上传轨迹 \( \hat{\tau}_t \) 及元数据到云端。
3. 云端批评家检查缓存，若无匹配则评估轨迹，准入高质量经验（按公式(5)）。
4. 云端定期聚合相同子目标标识符的经验，形成全局指导并存储于知识库。
5. 边缘代理发起新子目标时，根据标识符检索全局指导，与重构历史一起组装提示执行。

## 6. 主要结论与发现
- **场景A**：CoMIC将整体SR从0.00提升至6.50，PR从5.87提升至15.99，GA从32.53提升至73.94，同时平均上下文token减少27.88%。在Blocksworld和Tyreworld上增益最显著。
- **场景B**：异构强代理产生的高质量轨迹可提升云端指导质量，但弱代理受限于基础能力，SR提升仅+1.00（整体），但PR和GA继续提升。
- **消融**：有云配置相比纯本地显著提升PR和SR，证明云端反思有效。
- **局限性**：弱模型无法生成可行子目标或理解复杂指导时，端到端成功受约束。

## 7. 优点
- **免参数更新**：无需微调，适合资源受限和异构边缘节点，便于扩展。
- **集中反思、分散执行**：将计算密集型反思上云，边缘保持轻量，符合人认知中的“快思考-慢思考”模式。
- **层次化记忆+选择性重扩**：有效控制上下文长度，避免令牌爆炸。
- **基于语义子目标标识符的跨代理聚合**：支持异构经验融合，提升共享知识效率。
- **异步通信**：边缘执行不阻塞，保证实时性。

## 8. 不足与局限
- **端到端成功率仍受弱模型基础能力限制**：若边缘模型无法合理分解子目标或执行子任务，云端指导作用有限（如Gripper和Jericho SR=0）。

- **置信度准入机制依赖LLM自我报告分数**，可能引入偏差。
- **仅评估了五个任务**，未涵盖更复杂的交互或动态环境。
