## 摘要
由多模态大语言模型（MLLMs）驱动的移动GUI代理在人机智能方面显示出巨大潜力。然而，当前研究主要聚焦于被动任务执行，而缺乏对用户意图的全面理解-预测-执行过程，而这正是主动代理的核心需求。在本文中，我们提出Act2Intention框架，通过整合理解、预测用户意图和执行决策来构建主动移动代理。首先，我们通过数据收集和验证生成构建了Act2Intention Bench，包含52个应用中超过72,511个意图和700,000个动作，从而建立了首个通过连续意图-动作轨迹评估主动代理的基准。我们进一步开发了Act2Intention Agent，通过主动导向的意图理解、个性化主动意图预测和经验引导的意图执行来实现主动服务。实验结果表明，在同一代理框架下，基于Act2Intention Bench进行监督微调，在意图理解、预测和执行方面分别比未微调模型绝对提升了+32.0 Acc-S、+10.25 Acc-S和+6.9 SSR点。这一成功凸显了Act2Intention Bench的必要性和价值，它为开发和评估主动代理建立了标准化平台，从而为意图驱动的人机交互研究铺平了道路。

## Abstract
Mobile GUI Agents powered by multimodal large language models (MLLMs) show promise in human-computer intelligence. However, current research primarily focuses on reactive task execution while lacking a comprehensive understanding-prediction-execution process for user intentions, which are the core requirements of active agents. In this paper, we propose the Act2Intention framework that builds an active mobile agent by integrating understanding, predicting user intentions, and executing decisions. First, we construct the Act2Intention Bench through data collection and validated generation, comprising 72,511 intentions and over 700,000 actions across 52 apps, thereby establishing the first benchmark for evaluating proactive agents via continuous intention-action trajectories. We further develop the Act2Intention Agent, achieving proactive services through Proactive-oriented Intention Understanding, Personalized Proactive Intention Prediction, and Experience-guided Intention Execution. Experimental results show that supervised fine-tuning on Act2Intention Bench yields absolute improvements of +32.0 Acc-S, +10.25 Acc-S, and +6.9 SSR points over non-fine-tuned counterparts under the same agent framework for intention understanding, prediction, and execution, respectively. This success underscores the necessity and value of the Act2Intention Bench, which establishes a standardized platform for developing and evaluating proactive agents and consequently paves the way for research on intention-driven human-computer interaction.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 现有移动 GUI 智能体（如 AutoGLM、UI-TARS 等）已具备较强的任务执行能力，但在本质上仍属于**被动执行者（reactive actor）**——它们依赖用户给出明确指令才能工作。现实场景中，用户往往不善于也不愿意用文字或语音明确表达意图，尤其在需要前瞻性和自主决策的场景中，被动代理无法提供真正的帮助。
- 为此，论文将主动移动智能体（active/proactive agent）的能力定义为一条完整链路：**理解（Understanding）→ 预测（Prediction）→ 执行（Execution）**。核心是从连续的 GUI 底层动作流中推断用户的真实意图，基于历史意图轨迹和用户画像预测下一个意图，并在用户确认后将其落地为可执行的 GUI 操作。
- 当前尚无针对**连续多意图建模**的移动 GUI 数据集——现有数据集（AiTW、Android Control、AMEX 等）都是离散的单任务数据，缺乏连续的“意图-动作”轨迹。这是阻碍主动移动智能体研究的根本缺口。

## 2. 论文提出的方法论

**核心框架 — Act2Intention：**

论文提出了“理解→预测→执行”三阶段的多智能体框架，包含三个核心模块：

**（1）主动导向的意图理解（Proactive-oriented Intention Understanding）**

- **动作描述**：使用 VLM 将每个 GUI 动作转化为自然语言描述 \(d_t = f(d_t \mid o_t, a_t, o_{t+1})\)，结合动作前后的截图、点击区域高亮等信息，输出标准格式“[App/界面]，[操作]，目的为…”。动作描述作为下游意图推理的中间语义表示。
- **会话分割**：从连续的动作描述流中识别意图边界（\(\bigcup_{i=1}^{m}\{p_i,\dots,q_i\} = f(\{d_1,\dots,d_M\})\)），标记每个意图片段的起止索引。
- **意图理解**：对每个分割片段进行语义归纳，输出自然语言的意图描述 \(I_{1:m} = f_\phi(\tau^{des}_{1:m})\)。

**（2）个性化主动意图预测（Personalized Proactive Intention Prediction）**

- 基于历史意图序列 \(I_{1:t}\)、用户画像 \(P\) 和当前时间 \(T\)，预测用户的下一潜在意图 \(\hat{I}_{t+1} = f_\theta(I_{1:t}, T, P)\)。
- 预测结果为“意图类别 + 行为描述”，在设备唤醒等预定义触发时机推送给用户确认。

**（3）经验引导的意图执行（Experience-guided Intention Execution）**

- 用户确认意图后，通过 all-MiniLM-L6-v2 对意图进行文本嵌入，在同类别意图中检索最相似的历史意图-动作轨迹作为引导经验，增强 GUI 代理的步骤决策。
- 执行遵循 \(a_{t+1} = f_\pi(I, h_{t-1}, o_t, \tau^*)\)，其中 \(\tau^*\) 是从用户历史中检索到的相似任务轨迹。

**基准构建（Act2Intention Bench）：**

- 采用三级数据管线：真实轨迹（RR）→ 基于真实画像的生成轨迹（RG）→ 基于生成画像的生成轨迹（GG）。
- 使用 LLM 生成与用户画像一致的意图轨迹（LLM + Deepseek-R1 推理生成），再利用 UI-TARS 在 Android 模拟器上并行执行合成意图、收集 GUI 动作轨迹。
- 经过两步质量过滤：**意图过滤**（重建画像计算余弦相似度，阈值 0.7，保留 92.63%）与**动作轨迹过滤**（基于意图、元数据、终态截图进行完整性/正确性/终态合理性判定，保留 87.03%）。

## 6. 论文的主要结论与发现

1. **SFT 显著提升三任务表现**：在同一智能体框架下，基于 Act2Intention Bench 微调后，意图理解 Acc-S 提升 +32.0，意图预测 Acc-S 提升 +10.25，意图执行 SSR 提升 +6.9。部分模型（如 Qwen-2.5-7B-SFT）Acc-G 从 12.14 提升至 100。
2. **理解模块对预测是必要前置**：移除理解模块后，GPT-4o 的 Acc-C 从 34.5 降至 12.0，Qwen-2.5-7B-SFT 从 50.0 降至 8.5——直接从低层动作预测意图会引入噪声与低效。
3. **动作描述不是当前瓶颈**：使用 Qwen-VL-Max 生成的动作描述（Acc-S 0.64）与参照描述（0.49）在理解性能上差距较小，说明描述质量在可接受范围内。
4. **Persona 有助于类别预测**：加入 persona 后多数模型 Acc-C 提升（如 Deepseek-7B-SFT 从 53.07 提至 55.5），但对语义细节（Acc-S）提升不一致，说明画像主要帮助粗粒度偏好推理。
5. **真实数据与生成数据互补**：RR+RG+GG 组合训练效果优于任意单一子集（understanding Acc-G 100 / Acc-S 0.49），单一 GG 虽然在分割上表现好但语义准确率低（Acc-S 0.35）。
6. **OOD 退化明显**：SFT 提升 ID 性能但同时减小了 OOD 泛化能力，例如 Llama-3.1-8B-SFT 在理解任务上 Acc-G 下降 12.73，预测任务 Acc-C 下降 10.65。
7. **端到端系统仍受限**：预测意图的端到端 SR 最高仅 22.7（UI-TARS-7B-SFT），而替换为 ground-truth 意图后 SR 提升至 47.6。意图预测不准确与长程 GUI 执行能力不足是当前两大瓶颈；置信度回退机制可将 SR push 提升至 34.6（threshold 0.80 时 34.6%）。

## 7. 优点

- **填补基准空白**：首次构建了包含**连续多意图-动作轨迹**的移动 GUI 基准（72,511 意图 / 700k 动作 / 52 应用），为主动移动智能体研究提供标准化评估平台。
- **清晰的问题抽象**：将主动服务拆解为可验证的“理解 → 预测 → 执行”三阶段，每阶段均有明确的任务定义、公式和可量化指标。
- **多层次数据质量控制**：采用真实数据 + 生成数据的混合路线，并用两步过滤（画像一致性 + 轨迹成功验证）保障数据质量，还引入人工真实性评估。
- **实验设计完整**：从模型对比、消融分析、OOD 泛化、端到端评估到误差溯源，形成了从模块到系统的完整验证链条。
- **开源开放**：代码与基准数据已开源，有助于后续研究复现与扩展。

## 8. 不足与局限

- **数据偏差风险**：原始数据仅来自 90 名匿名参与者、一款手机厂商收集渠道，且受隐私协议限制未公开参与者人口统计信息（年龄、性别、地域、技术背景），样本代表性不足，可能反映特定人群的使用偏好。合成数据虽扩大了规模，但可能包含 LLM 生成的理想化或刻板模式。
- **干预时机缺失**：基准关注“预测什么意图”，但未包含“何时打扰用户最合适”的标签或任务。预测仅在预定义事件（如设备唤醒）时触发，缺乏对通知时机建模。
- **真实用户评估缺失**：未开展实地用户研究来验证建议的有用性、及时性和非侵入性，HCI 领域的用户接受度关键因素（相关性、时机、控制感）尚未被实证检验。
- **端到端性能差距大**：预测意图的端到端 SR（22.7）远低于 ground-truth 意图（47.6），且执行层 SSR 偏低，说明意图预测精度和长程执行鲁棒性仍是重大挑战。
- **指标局限**：SSR 是保守的逐步骤精确匹配，会漏判功能等价的操作路径；Acc-S 的语义向量相似度本身对粒度差异敏感，低 Acc-S 不必然意味着意图理解完全失败（论文误差分析也确认了这一点）。
- **SFT 损害 OOD 泛化**：微调在 ID 测试集上增益显著，但 OOD 性能下降，暗示模型可能过度拟合训练分布，如何保持持续适应能力没有得到解决。
- **部署挑战**：真实部署涉及敏感截图/操作数据的隐私问题，以及大模型感知、预测和执行在移动端上的延迟与能耗问题；当前实验在模拟器环境下完成，真实设备性能可能更差。
